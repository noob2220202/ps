# 문제지 — 영상 화면 분석

41초짜리 화면 녹화를 4fps로 쪼개서 분석한 결과입니다. 괄호 안은 영상 타임스탬프.
픽셀 값은 영상(480px 폭) 기준을 360px 폭 CSS로 환산(×0.75)한 값입니다.

## 화면 흐름

```
앱 실행 → 스플래시(노랑) → 검은 로딩 → 홈(다크)
  홈 ─ 즐겨찾기 계좌 탭 → 계좌 상세(라이트) ─ 전체보기 → 전체 내역 ─ 거래 탭 → 거래 상세
  홈 ─ mini 카드 탭 → mini 계좌(베이지)
  뒤로 오면 홈 상단 AI 배너 문구가 매번 바뀜
```

## 1. 스플래시 (0.0 ~ 5.3s)

- (0.5) 런처 아이콘 자리에서 노란 둥근 사각형이 화면 전체로 펼쳐짐
- (2.0) 화면 중앙에 큰 **B** 로고
- (3.0) B가 작아짐 → (3.25) 오른쪽으로 `kakaobank` 워드마크가 펼쳐지며 B는 왼쪽으로 밀림
- 동시에 아래쪽에 광고: 앨범 로고 / `10.27 미니 2집 발매 [AD]` / 둥근 사진 카드
- 배경 `#ffe100`

## 2. 부팅 로딩 (5.5 ~ 10.7s)

- 검은 화면, 가운데 회색 머티리얼 스피너

## 3. 홈 (11.0s ~)

두 단계로 그려짐:

1. (11.0) 헤더에 **사용자 이름** + 알림벨(빨간 점), 하단 탭바. (11.5) mini 카드, 계좌 카드(타행 계좌는 아이콘 회색, 잔액 `?원`), 칩, `+ 상품 추가`, `간편 홈 | 화면 편집`
2. (11.75) 이름 자리에 **AI 배너 pill**이 생기며 무지개 링 스피너 → 문구가 한 글자씩 타이핑. 광고 배너가 위에서 밀고 들어오고, `AI 목표적금 출시` 행, `카드` 섹션이 끼어듦. 타행 잔액이 `0원`으로 바뀜

구성 (위→아래):
- AI pill: `#262626`, 아이콘 + 1~2줄 문구, 2줄짜리는 오른쪽에 작은 X
- 광고: `AND2BLE / 미니 2집 발매 / 10월 27일 오후 6시 / [MV 보러가기]`, 오른쪽 사진, X, AD 뱃지
- mini 카드: 베이지 `#c4bbac`, B 아이콘, `0원`, `{이름} mini`, `이체`
- 계좌 카드 `#262626`: 👋 `120,268원` ★[한도계좌] / 농협 `0원` / AI 목표적금(X로 닫힘) / 칩 `내 계좌 >` | `+ 통장` `+ 저축` `+ 다른 금융 계좌` (가로 스크롤)
- 카드 섹션: `카드 >`, 카드 썸네일, `203,070원 / 이번달 쓴 돈`, `내역 보기`
- 하단 탭바 `#2d2d2d`: 홈 / 혜택• / AI / 투자 / 전체• (상단 모서리 둥글게)

AI pill 문구 (홈 진입마다 다음 것으로):
1. 🔷 `원금 지키는 펀드, 정말 가능할까요?`
2. 🪙 `지난 달, 모임통장 / 어디에 제일 많이 썼을까요?`
3. 🪙 `회비 안 낸 모임멤버 / 한 번에 모아봤어요`

재진입 시: 이전 문구 → 스피너 → 새 문구 타이핑 (34.0 → 34.25 → 34.5)

## 4. 계좌 상세 (18.0 ~ 21.5s)

- (18.0) 계좌 행 탭 → 행 위에 작은 스피너 → (18.75) 밝은 스켈레톤이 홈 위로 페이드인
- (19.25) 본문: 라벤더 그라데이션 위 캐릭터 3명 일러스트, 그 아래 걸치듯 흰 pill에 `지난 달보다 얼마나 더 썼을까요?` 타이핑
- 흰 카드: 👋 / ★ [계좌번호] / `120,268원` / `이체하기` `채우기`
- `최근 내역` + `전체보기`, 흰 카드에 최근 3건(날짜별 그룹)
- `모임 관리`: 😀 모임 멤버 `2명 참여 중`(파랑), 💵 회비 입금현황
- (20.75) 스크롤하면 일러스트가 흐려지며 올라감, 헤더(뒤로/설정)는 고정

## 5. 전체 내역 (21.75 ~ 27.25s)

- 스켈레톤 → 헤더(뒤로, 가운데 ⭐), 캐릭터 아바타, `120,268 원`
- 검색 박스 `3개월 · 전체 · 최신순 ∨`
- 날짜별 거래 목록. 입금은 부호 없이 파란색 `7원`
- 스크롤 내리면 하단에 `↑ 맨 위로` 버튼이 떠오름
- (27.25) 행을 누르면 회색 하이라이트 후 이동

## 6. 거래 상세 (27.5 ~ 31.3s)

- 태그/제목/메모 줄은 즉시, 아래는 스피너 → 내용
- 그룹 1: 거래시각, 거래구분 / 그룹 2: 거래금액(굵게), 거래 후 잔액, 카드정보 / 그룹 3: 사용처, 주소, 전화번호
- `'상호명' 검색하기 >`(파랑), `1/N 빵나누기`(외곽선 버튼)
- 하단 고정: 남색 공유 버튼 + 노란 `확인` (누르면 어두워지고 뒤로)

## 7. mini 계좌 (37.25 ~ 39.5s)

- 상단 베이지: 제목 `{이름} mini`, 밑줄 친 계좌번호, `0원`, `이체하기` `용돈요청[NEW]`
- 흰 영역: 검색 줄 `3개월 · 전체 · 최신 ∨`, 흰 원형 스피너 → `거래 내역이 없습니다.`
