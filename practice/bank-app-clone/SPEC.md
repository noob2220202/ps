# 문제지 — 영상 화면 분석

> 금액·거래처·계좌번호 등 실제 값은 모두 `{잔액}` 같은 자리표시자로 바꿨습니다. 코드의 데이터도 전부 가상 예시값입니다.

41초짜리 화면 녹화를 4fps로 쪼개서 분석한 결과입니다. 괄호 안은 영상 타임스탬프.
픽셀 값은 영상(480px 폭) 기준을 360px 폭 CSS로 환산(×0.75)한 값입니다.

## 화면 흐름

```
앱 실행 → 스플래시(노랑) → 검은 로딩 → 홈(다크)
  홈 ─ 즐겨찾기 계좌 탭 → 계좌 상세(라이트) ─ 전체보기 → 전체 내역 ─ 거래 탭 → 거래 상세
  홈 ─ mini 카드 탭 → mini 계좌(베이지)
  뒤로 오면 홈 상단 AI 배너 문구가 매번 바뀜
```

## 1. 스플래시 (0.0 ~ 5.3s)

- (0.5) 런처 아이콘 자리에서 노란 둥근 사각형이 화면 전체로 펼쳐짐
- (2.0) 화면 중앙에 큰 **B** 로고
- (3.0) B가 작아짐 → (3.25) 오른쪽으로 `kakaobank` 워드마크가 펼쳐지며 B는 왼쪽으로 밀림
- 동시에 아래쪽에 광고: 앨범 로고 / `10.27 미니 2집 발매 [AD]` / 둥근 사진 카드
- 배경 `#ffe100`

## 2. 부팅 로딩 (5.5 ~ 10.7s)

- 검은 화면, 가운데 회색 머티리얼 스피너

## 3. 홈 (11.0s ~)

두 단계로 그려짐:

1. (11.0) 헤더에 **사용자 이름** + 알림벨(빨간 점), 하단 탭바. (11.5) mini 카드, 계좌 카드(타행 계좌는 아이콘 회색, 잔액 `?원`), 칩, `+ 상품 추가`, `간편 홈 | 화면 편집`
2. (11.75) 이름 자리에 **AI 배너 pill**이 생기며 무지개 링 스피너 → 문구가 한 글자씩 타이핑. 광고 배너가 위에서 밀고 들어오고, `AI 목표적금 출시` 행, `카드` 섹션이 끼어듦. 타행 잔액이 `0원`으로 바뀜

구성 (위→아래):
- AI pill: `#262626`, 아이콘 + 1~2줄 문구, 2줄짜리는 오른쪽에 작은 X
- 광고: `AND2BLE / 미니 2집 발매 / 10월 27일 오후 6시 / [MV 보러가기]`, 오른쪽 사진, X, AD 뱃지
- mini 카드: 베이지 `#c4bbac`, B 아이콘, `0원`, `{이름} mini`, `이체`
- 계좌 카드 `#262626`: 👋 `{잔액}` ★[한도계좌] / 농협 `0원` / AI 목표적금(X로 닫힘) / 칩 `내 계좌 >` | `+ 통장` `+ 저축` `+ 다른 금융 계좌` (가로 스크롤)
- 카드 섹션: `카드 >`, 카드 썸네일, `{이번달 사용액} / 이번달 쓴 돈`, `내역 보기`
- 하단 탭바 `#2d2d2d`: 홈 / 혜택• / AI / 투자 / 전체• (상단 모서리 둥글게)

AI pill 문구 (홈 진입마다 다음 것으로):
1. 🔷 `원금 지키는 펀드, 정말 가능할까요?`
2. 🪙 `지난 달, 모임통장 / 어디에 제일 많이 썼을까요?`
3. 🪙 `회비 안 낸 모임멤버 / 한 번에 모아봤어요`

재진입 시: 이전 문구 → 스피너 → 새 문구 타이핑 (34.0 → 34.25 → 34.5)

## 4. 계좌 상세 (18.0 ~ 21.5s)

- (18.0) 계좌 행 탭 → 행 위에 작은 스피너 → (18.75) 밝은 스켈레톤이 홈 위로 페이드인
- (19.25) 본문: 라벤더 그라데이션 위 캐릭터 3명 일러스트, 그 아래 걸치듯 흰 pill에 `지난 달보다 얼마나 더 썼을까요?` 타이핑
- 흰 카드: 👋 / ★ [계좌번호] / `{잔액}` / `이체하기` `채우기`
- `최근 내역` + `전체보기`, 흰 카드에 최근 3건(날짜별 그룹)
- `모임 관리`: 😀 모임 멤버 `2명 참여 중`(파랑), 💵 회비 입금현황
- (20.75) 스크롤하면 일러스트가 흐려지며 올라감, 헤더(뒤로/설정)는 고정

## 5. 전체 내역 (21.75 ~ 27.25s)

- 스켈레톤 → 헤더(뒤로, 가운데 ⭐), 캐릭터 아바타, `{잔액} 원`
- 검색 박스 `3개월 · 전체 · 최신순 ∨`
- 날짜별 거래 목록. 입금은 부호 없이 파란색 (예: `10원`)
- 스크롤 내리면 하단에 `↑ 맨 위로` 버튼이 떠오름
- (27.25) 행을 누르면 회색 하이라이트 후 이동

## 6. 거래 상세 (27.5 ~ 31.3s)

- 태그/제목/메모 줄은 즉시, 아래는 스피너 → 내용
- 그룹 1: 거래시각, 거래구분 / 그룹 2: 거래금액(굵게), 거래 후 잔액, 카드정보 / 그룹 3: 사용처, 주소, 전화번호
- `'상호명' 검색하기 >`(파랑), `1/N 빵나누기`(외곽선 버튼)
- 하단 고정: 남색 공유 버튼 + 노란 `확인` (누르면 어두워지고 뒤로)

## 7. mini 계좌 (37.25 ~ 39.5s)

- 상단 베이지: 제목 `{이름} mini`, 밑줄 친 계좌번호, `0원`, `이체하기` `용돈요청[NEW]`
- 흰 영역: 검색 줄 `3개월 · 전체 · 최신 ∨`, 흰 원형 스피너 → `거래 내역이 없습니다.`

## 8. 아이폰 버전 (`?os=ios`)

원본 영상은 갤럭시라서, 아이폰 쪽은 **iOS 27(2026년 9월) + iPhone 17 Pro** 기준으로 시스템 UI만 바꿨습니다.
앱 자체 디자인(색, 카드, 광고)은 두 OS가 같고, 달라지는 건 "OS가 그려주는 부분"입니다.

| 항목 | 갤럭시 (영상) | 아이폰 (iOS 27) |
|---|---|---|
| 화면 크기 | 360 × 800 | 402 × 874 (iPhone 17 Pro) |
| 상단 | 상태바 26px, 펀치홀 | 상태바 54pt + 다이내믹 아일랜드, 시간은 섬 왼쪽 가운데 |
| 하단 | 제스처 바 | 홈 인디케이터 + 안전영역 34pt |
| 뒤로가기 버튼 | ← 화살표 | 유리 원 안의 ‹ (누르면 살짝 부풀어 오름) |
| 탭바 | 바닥에 붙은 둥근 바 | 가장자리에서 21pt 띄운 **Liquid Glass 캡슐**, 선택 탭에 밝은 캡슐, 아래로 스크롤하면 선택 탭 하나만 남은 작은 캡슐로 축소 |
| 화면 전환 | 새 화면 페이드인, 뒤로는 즉시 | 오른쪽에서 밀고 들어옴(이전 화면은 30%만 밀리며 어두워짐), 뒤로는 반대 |
| 뒤로가기 제스처 | 시스템 뒤로 | **왼쪽 가장자리 스와이프**: 손가락 따라 화면이 밀리고 뒤 화면이 보임, 1/3 넘으면 확정 |
| 로딩 스피너 | 머티리얼 호 스피너 | 살 8개 UIActivityIndicator |
| 글꼴 | Pretendard | SF Pro + Apple SD 산돌고딕 Neo (아이폰에서 열면 적용) |

참고한 자료: iOS 27 Liquid Glass 변경점(기본값이 iOS 26보다 더 불투명, 탭바 개선),
iOS 26 탭바 사양(21pt 떠 있는 캡슐, 스크롤 시 축소), iPhone 17 Pro 화면 사양(402×874pt, 상단 62/하단 34pt).

## 9. 라이트 모드 홈 (실제 앱 스크린샷 기준)

실제 앱은 **시스템 다크모드 설정**을 따라 홈 테마가 바뀝니다 (영상=다크, 스크린샷=라이트).
상세/내역/거래 화면은 두 모드 모두 밝은 화면입니다.

- 배경 `#f4f4f4`, 카드 흰색, 버튼 `#f5f5f5`, 본문 `#212121`, 보조 글자 `#656565`
- 계좌 아이콘: 연회색 원 안의 분홍 손 / 초록 원 농협 / 연민트 원 AI 목표적금
- **카드 섹션 하나 안에** 3줄:
  1. `카드 >` 제목, 끈 달린 카드 썸네일 + `{이번달 쓴 돈}` + `내역 보기`
  2. 카드 끈이 내려오는 자리 옆에 **`현`만 노란색**인 `현금 돌려받을 기회 N건이 있어요` (아이콘 없음)
  3. 티머니 로고 + `티머니 잔액` (크고 굵게) + `조회` `충전`
- 그 아래 `+ 상품 추가` (둥근 흰 버튼)
- 하단 탭바 흰색, 아이콘 검정, 홈은 채워진 아이콘

## 10. 두 번째 녹화(라이트 모드, 끝까지 스크롤)에서 새로 알게 된 것

- **AI 말풍선**: 흰 캡슐 뒤에 하늘색↔노란색 은은한 글로우. 문구 예: `코스피 7천, 다시 올 수 있을까요?`
- **상단 배너 캐러셀**: 3장이 자동으로 옆으로 넘어감, 오른쪽 위 점 3개(현재 = 검정)
  - 굵은 2줄 제목 + 연노랑 작은 버튼(`#fff4b2` 배경, `#6f6a08` 글자) + 오른쪽 3D 이미지
  - `mini카드로 삼성월렛 이용하고 / 2천 포인트 받아가기 [삼성월렛으로 이동]`
  - `우리 동네 가까운 봉사활동 찾기 / 카카오뱅크에서 시작하세요 [더 알아보기]`
  - `피카PC방 전용 결제 이벤트 / mini카드로 마일리지 받기 [자세히 보기]`
- **현금 돌려받을 기회 N건**: 약 10초마다 `현금 돌려받을 기회 N건` 글자 위로 노랑→초록→하늘→파랑→하늘→초록→노랑 색 띠가 왼쪽에서 오른쪽으로 약 2초간 지나감 (영상 2.4~4.6초, 12.8~15초)
- **`간편 홈 | 화면 편집` 아래**:
  - 바로가기 카드: 우리학교 시간표 / 정부지원금 찾기 / 모바일 신분증 이용하기 / mini 26일저금 (각 3D 아이콘)
  - 네이티브 광고 카드: 연회색(`#f6f6f6`) 둥근 박스, `○○ 앱에서 구매하기 ›`, 굵은 상품명, `AD ○○ 광고입니다`, 오른쪽 상품 사진, 오른쪽 위 ⓘ
- 라이트 모드 페이지 배경은 **흰색**. 카드 사이가 회색으로 보이는 건 카드 그림자
