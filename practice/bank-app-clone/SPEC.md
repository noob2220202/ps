# 클론코딩 스펙 (문제지)

은행 앱 화면 녹화를 보고 구조를 분석해 만든 요구사항입니다.
실제 서비스의 로고/브랜드명/코드는 사용하지 않고, 화면 구성과 인터랙션만 참고합니다.
데이터는 전부 `src/data/mockData.ts`의 가짜 데이터를 씁니다.

## 진행 방법 (이미 되어 있는 것 / 직접 할 것)

**이미 되어 있는 것 (보일러플레이트):**
- Vite + React + TypeScript + react-router-dom 세팅
- 타입 정의 (`src/types/bank.ts`)
- mock 데이터 (`src/data/mockData.ts`)
- 페이지 간 라우팅, URL 파라미터로 데이터 찾기, 페이지 이동

**직접 채워야 할 것:**
- `src/components/*.tsx` 안의 `TODO` 부분 (실제 마크업/스타일/로직)
- 각 페이지의 레이아웃

막히면 컴포넌트 하나 완성할 때마다 저한테 보여주세요. 스펙대로 됐는지, 버그는 없는지, 더 짧게 쓸 방법은 없는지 리뷰해드릴게요.

## 1. Home 화면 (`HomePage`, `/`)

상단부터 순서대로:

1. **검색/AI 배너 영역** — 돋보기 아이콘 + "지난 달보다 얼마나 더 썼을까요?" 같은 AI 추천 문구가 번갈아 뜨는 pill 모양 바, 오른쪽에 알림벨 아이콘(안 읽은 알림이 있으면 빨간 점)
2. **계좌 리스트** (`AccountCard` 반복) — `mockAccounts` 순서대로:
   - 즐겨찾기 계좌(`isStarred: true`)는 밝은 배경 + 손 이모지 + 별 뱃지로 다른 계좌와 구분
   - 계좌명(nickname), 잔액(balanceWon, 천단위 콤마 + "원"), 오른쪽에 둥근 "이체" 버튼
   - 카드를 클릭하면 `/account/:id`로 이동 (이미 연결됨, `onClick` prop만 써서 렌더링하면 됨)
   - `badge`가 있으면 계좌명 옆에 작은 태그로 표시 (예: "한도계좌")
3. **이번달 쓴 돈 카드** — `mockMonthlyCardSpend`의 라벨 + 금액, "내역 보기" 버튼
4. **모임 관리** (`GroupAccountCard`) — 모임 이름, 멤버 수, 회비 미납 인원이 1명 이상이면 "회비 안 낸 모임멤버 있어요" 같은 안내 문구
5. **하단 탭바** (`BottomNav`) — 홈 / 혜택 / AI / 투자 / 전체, 5개 아이콘+라벨. 현재 페이지(홈)는 강조 표시

## 2. 계좌 상세 화면 (`AccountDetailPage`, `/account/:accountId`)

1. 상단: 뒤로가기 화살표(왼쪽), 설정 톱니바퀴 아이콘(오른쪽)
2. **잔액 섹션**: 별 아이콘 + "계좌번호" 라벨, 잔액을 아주 큰 글씨로("452,300원"), 아래에 "이체하기" / "채우기" 버튼 2개 나란히
3. **최근 내역** (`TransactionList`):
   - 날짜별로 그룹핑해서 "10.27" 같은 날짜 헤더 먼저, 그 아래 해당 날짜 거래들
   - 각 거래(`TransactionItem`): 왼쪽에 시각+거래처명+태그(파란 글씨, 예: `#체크카드`), 오른쪽에 금액(입금은 파란색, 출금은 흰색/검은색)과 그 아래 작은 글씨로 거래 후 잔액
   - 거래 아이템 클릭 시 `/account/:accountId/transaction/:txId`로 이동 (이미 연결됨)

## 3. 거래 상세 화면 (`TransactionDetailPage`, `/account/:accountId/transaction/:txId`)

1. 상단: 태그(`#체크카드` 등, 파란 글씨), 거래처명을 큰 글씨 제목으로
2. "메모할 수 있어요 (최대 20자)" 입력란 + 연필 아이콘
3. key-value 형태의 상세 정보 목록 (좌측 라벨, 우측 값):
   - 거래시각 (transactedAt)
   - 거래구분 (transactionType)
   - 거래금액 (amountWon, 굵게)
   - 거래 후 잔액 (balanceAfterWon)
   - 카드정보 (cardInfo, 있을 때만)
   - 사용처 (merchant)
   - 주소 (merchantAddress, 있을 때만)
   - 전화번호 (merchantPhone, 있을 때만)
4. 하단: "'상호명' 검색하기" 링크, 공유 아이콘 버튼 + "확인" 큰 버튼 (노란색)
