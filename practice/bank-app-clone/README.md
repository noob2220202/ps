# 은행 앱 클론코딩 (학습용)

화면 녹화 영상을 프레임 단위로 분석해서 화면 구성, 색상, 애니메이션, 광고, 로딩 순서까지
그대로 재현한 React 클론입니다. 비상업적 학습 목적이며 상표권은 각 소유자에게 있습니다.

## 실행

Node **22.13 이상** 필요 (내장 SQLite 사용).

```bash
npm install
npm run dev        # 카카오뱅크: API 서버 + 화면 동시 실행 → http://localhost:5173  (?skip 붙이면 스플래시 생략)
npm run dev:nh     # NH 콕뱅크:  → http://localhost:5174 (API 8788)
npm run dev:hana   # 하나원큐:   → http://localhost:5175 (API 8789)
```

### VPS에 띄우기 (포트 9101)

```bash
npm ci
python3 scripts/extract-bank-icons.py 은행선택.mp4 은행선택1.jpg 은행선택2.jpg   # 은행 아이콘 (선택)
npm run build
npm start                              # http://서버IP:9101
# 꺼지지 않게: pm2 start "npm start" --name bank   (pm2 save 로 재부팅 후에도)

# NH 콕뱅크는 서버를 하나 더 (같은 빌드, 포트 9103, 데이터 따로)
npm run start:nh                       # http://서버IP:9103
# pm2 start "npm run start:nh" --name nh

# 하나원큐도 서버를 하나 더 (같은 빌드, 포트 9105, 데이터 따로)
npm run start:hana                     # http://서버IP:9105
# pm2 start "npm run start:hana" --name hana
```

서버 하나가 화면과 API를 같이 줍니다. 포트 변경은 `PORT=8080 npm start`.
**서버 하나는 앱 하나만** 엽니다: `npm start` = 카카오뱅크(기본 9101, 데이터 `server/data/`),
`npm run start:nh` (= `APP=nh`) = NH 콕뱅크(기본 9103, 데이터 `server/data-nh/`),
`npm run start:hana` (= `APP=hana`) = 하나원큐(기본 9105, 데이터 `server/data-hana/`). 프로필 목록부터 전부 따로입니다.
데이터는 `server/data/`(SQLite)에 저장되고 커밋되지 않습니다. 프로필 목록은 `app.db`, 프로필별 은행 데이터는 `profiles/<id>.db`.
폴더째 지우면 예시 데이터의 "홍길동" 프로필 하나로 다시 시작. 예전 버전의 `bank.db`가 있으면 첫 프로필로 자동으로 옮겨집니다.

PC 브라우저에서는 폰 프레임 안에, 폰(폭 500px 이하)으로 열면 전체 화면으로 보입니다.

**갤럭시 / 아이폰 전환**: 프레임 아래 스위치를 누르거나 주소에 `?os=ios` / `?os=android`.
**라이트 / 다크**: 기본은 폰(시스템) 설정을 따름. 스위치나 `?theme=light` / `?theme=dark`로 고정.
아이폰으로 접속하면 자동으로 아이폰 버전. 아이폰 버전은 iOS 27 Liquid Glass 탭바, 다이내믹 아일랜드,
push 화면 전환, 왼쪽 가장자리 스와이프 뒤로가기가 들어가 있습니다.

## 👤 프로필 (넷플릭스처럼)

접속하면 먼저 **"누구의 은행을 열까요?"** 화면이 나옵니다. 프로필마다 계좌·거래내역·받는 분과
기기(Galaxy/iPhone)·테마(라이트/다크) 설정이 따로 저장돼서, 고르면 그 프로필이 마지막으로 쓰던 상태로 열립니다.

- `+ 프로필 추가`: 이름·아바타·색 고르기. 새 프로필은 **카카오뱅크 통장 0원만 있는 빈 상태**로 시작 (최대 5개)
- `프로필 관리`: 이름·아바타 수정, 삭제 (삭제하면 그 프로필의 데이터도 지워짐)
- 새 탭/창으로 들어올 때마다 다시 고름. 쓰던 중에 바꾸려면 🔔 → 기본 → `프로필 바꾸기`

## 🔑 로그인 · 계정 (은행마다 따로)

접속하면 로그인부터. 계정은 **관리자가 만들어 줌** (회원가입 없음). 카카오뱅크(9101)·콕뱅크(9103)·하나원큐(9105)는 계정도 따로입니다.
- 계정마다 프로필(누구의 은행을 열까요?)이 여러 개, 프로필마다 은행 데이터가 따로
- 이용 기간: **1일 / 7일 / 30일 / 영구** — 계정을 만든 순간부터 줄어듦. 끝나면 로그인이 막히고(쓰던 중이면 로그인 화면으로),
  관리자가 연장하면 데이터 그대로 다시 사용
- **관리자**: 서버를 처음 켤 때 `admin` 계정이 생기고 비밀번호는 서버 로그와 `server/data/admin-password.txt`
  (콕뱅크는 `server/data-nh/`, 하나원큐는 `server/data-hana/admin-password.txt`)에 남음. 미리 정하려면 `ADMIN_PASSWORD=... npm start`.
  admin 으로 로그인 → 프로필 고르기 아래 `계정 관리` → 계정 만들기 / 연장(+1일·+7일·+30일·+영구) / 정지 / 비밀번호 바꾸기 / 삭제
- 예전에 있던 프로필은 관리자 계정 것으로 옮겨짐
- 로그아웃: 프로필 고르기 아래, 또는 🔔 → 기본

## 🟢 NH 콕뱅크 (두 번째 앱)

포트 9103(`npm run start:nh`)으로 들어가면 프로필 고르기 → 콕뱅크 다크 화면으로 열립니다 (간편비밀번호 로그인은 건너뜀).
카카오뱅크(9101)와 프로필·계좌·받는 분이 전부 따로입니다.

- 시작 화면 → **일반 홈**(다크): 큰글 스위치·MY·검색·알림·메뉴 / `NH농협 · 다른금융` 탭, `전체계좌 >` /
  계좌 카드(계좌가 여러 개면 옆으로 넘김, 🔒 잔액 숨기기, `거래내역 | 송금`) / `등록계좌` / 콕추천(가운데 카드가 커지는 가로 카드) /
  광고 배너 9개(3초마다 넘어감, ⏸) / 금융상품(적금 카드 4장, 타일 4개) / 마이데이터 / 아래 탭바.
  아래로 내리면 위 계좌 영역이 작은 카드(번호 ⌄, 잔액 `[송금]`)로 접혀 붙고, 탭바 대신 ↑ 버튼
- **라이트/다크 모드**: 폰(브라우저) 설정을 따르고, 🔔 → 기본 → 테마에서 시스템/라이트/다크로 고정.
  라이트 색은 라이트모드 녹화에서 화면마다 잰 값 (강조색이 보라가 아니라 청록)
- **콕송금**: 은행선택(은행/증권사 탭) → 계좌번호(키패드에 `콕`) → "얼마를 보낼까요?"(+1만/+5만/+10만/+100만/전액, 한글 금액,
  1일 송금 잔여한도 100만원) → 받는계좌·내계좌 표시 → 확인(거래메모) → 6개월간 안 보낸 분이면 "한번 더 확인" 시트 → 완료.
  아래 `최근송금 / 내계좌 / 자주쓰는` 목록에서 바로 고를 수도 있음. 받는 분은 카카오뱅크처럼 🔔 → 받는 분에 먼저 등록
- **전체계좌 조회**(홈 ☰ / 내계좌조회, `넓게` 스위치, `+ 농협계좌 등록`), **계좌별 거래내역**(계좌선택 시트, 입금/출금 조건),
  **거래 상세**(거래메모 저장, 입금은행·계좌 복사, `동일내역 송금` = 같은 계좌로 다시 보내기)
- 🔔 관리 패널은 홈의 종 버튼 (콕뱅크 색으로, 농협 관련만):
  - **계좌**: 계좌마다 이름(자립예탁금 등)·잔액·계좌번호 수정, `농협 계좌 추가`(이름, 13/14자리 번호, 시작 잔액 — 다른 은행은 추가 안 됨), 삭제
  - **받는 분**: 콕송금으로 보낼 상대 계좌 (하나은행 등 다른 은행으로도 보낼 수 있어서 은행은 전부 고를 수 있음)
  - **거래**, **기본**(프로필, 기기, 캡쳐모드, 녹화, 이름, 빈 상태로/예시 데이터로). 카카오뱅크 전용(테마, 카드, 세이프박스)은 없음

**실제 앱과 픽셀 단위로 맞춤** (스크린샷 720px·녹화 480px 기준):
Galaxy 폭 384dp(프레임 384 × 853.33), 글꼴 Pretendard, 색·크기·위치·글자 굵기, 0.5dp 선,
화면 전환(안드로이드 80/100ms 페이드), 시트 열림/닫힘 곡선, 버튼 누르면 "어둡게 + 점 3개" 로딩(그 아래에서 다음 화면으로 바뀜)까지.
남는 차이는 가짜 이름·계좌번호 글자, 상태바 시계 정도입니다.

화면 이미지(캐릭터, 메뉴 아이콘, 은행 아이콘 61개, 동전·방패, 완료 애니메이션 등, `src/assets/local/nh-*.png`)는
커밋돼 있습니다 (없으면 대체 그림). 다시 만들려면 콕뱅크 스크린샷·녹화에서 자릅니다 (필요: ffmpeg, Pillow, numpy):

```bash
python3 scripts/extract-nh.py --history 계좌별거래내역.jpg --video1 녹화1.mp4   # 공용 (계좌·앱 아이콘 등)
python3 scripts/nh-crops/home.py --home 홈.jpg --video1 녹화1.mp4               # 시작화면 (+ 예전 청소년 홈 그림)
python3 scripts/nh-crops/home-general.py --video3 일반홈녹화.mp4 --appstore 앱스토어_메인.png  # 일반 홈
python3 scripts/nh-crops/txdetail.py --detail-out 출금상세.jpg --light-frame 라이트_상세_프레임.png  # 라이트용 아이콘
python3 scripts/nh-crops/light-variants.py                                       # 다크에서 자른 그림의 라이트용(바탕만 교체)
python3 scripts/nh-crops/picker.py --video1 녹화1.mp4                           # 은행선택 아이콘
python3 scripts/nh-crops/send-who.py 녹화1.mp4                                  # 누구에게 보낼까요?
python3 scripts/nh-crops/confirm.py --video2 녹화2.mp4                          # 확인·완료
python3 scripts/nh-crops/history.py --history 계좌별거래내역.jpg                # 거래내역
python3 scripts/nh-crops/txdetail.py --detail-out 출금상세_아래스크롤.jpg        # 거래 상세
python3 scripts/nh-crops/accounts.py --accounts 전체계좌.jpg --register 녹화2_62.5초.png
```

## 💚 하나원큐 (세 번째 앱)

포트 9105(`npm run start:hana`)로 들어가면 로그인 → 프로필 고르기 → 시작화면(하나 1Q 원큐) → 하나원큐 홈.
라이트/다크 둘 다 실제 앱 녹화·스크린샷(2026-10-30)에 맞춰 그렸고, 폰 설정을 따르거나 스위치로 고를 수 있어요.

- **홈**: 대표계좌(입출금 · 통장 이름 · 번호 · 잔액 숨김) → 가져오기/보내기 → 전체계좌 → 배너 10장(자동 넘김, 멈춤) →
  작은 카드 줄 → 메뉴 6개 → 하나금융그룹 → 내 자산 → 홈 설정. 아래 검색 칩 + 탭(내려 스크롤하면 숨고 ⌄⌄ 버튼). 🔔 종 = 관리 패널
- **이체**: 보내기 → "누구에게 보낼까요?"(최근 · 내계좌 · 자주, ☆) → 직접 입력 → "이체할 계좌를 입력해 주세요"
  (삼성 키보드 숫자 자판, 은행/증권 고르기 시트, 번호가 아는 계좌면 은행 추천 칩) → "얼마를 보낼까요?"(1만·5만·10만·100만·전액,
  잔액보다 많으면 빨간 안내) → 받는분에게 표시 / 나에게 표시(자주쓰는문구) → 확인 → **비밀번호 없이 바로 완료**
  (실제 앱은 여기서 비밀번호 자판이 뜨는데 보안 화면이라 녹화가 막혀서 건너뜀)
- **완료**: 체크 → ☆ · 추가메모 · 자동이체 등록, 펼치기, 공유 / 거래내역 조회
- **거래내역조회**: 계좌 카드 → 1개월 · 전체 · 최신순, 기간, 잔액 토글 → 날짜별 목록(타행송금(지역농축협) · 체크카드 …)
- **거래내역상세**: 거래일시 · 거래구분 · 입금계좌 · 금액 · 수수료 · 거래후잔액 · 추가메모(눌러서 입력) → 다시 이체 / 자주쓰는 이체 등록
- 받는 분은 콕뱅크처럼 🔔 관리 → 받는 분 탭에 등록한 계좌만 보낼 수 있어요. 계좌 추가는 하나은행 계좌만

그림(은행 로고 · 배너 · 메뉴 아이콘 · 시작화면 로고 · 앱 아이콘)은 스크린샷·녹화에서 잘라 `src/assets/local/hana-*.png` 로:

```bash
python3 scripts/hana-crops/crops.py --shots <스크린샷 폴더> --dark 다크녹화.mp4
```

## 폰 아래 스위치 줄 (PC)

`Galaxy/iPhone` · `라이트/다크` · 🔋 배터리 잔량(0~100) · 🕐 상태바 시각(정한 시각부터 흘러감) · `실제 시간`(지금 시각으로) · `● 녹화`.
배터리·시각은 이 브라우저에 기억됨. 아이폰은 20% 이하면 배터리가 빨강

## ● 화면 녹화 (폰 아래 `Galaxy/iPhone · 라이트/다크` 옆 버튼)

누르면 앱이 검은 화면 → **시작화면부터 다시 켜지면서** 폰 화면만 녹화됩니다 (앱 켜지는 모습까지).
- **PC 크롬/엣지**: 공유 창에서 "이 탭" 선택 → 시작. 끝낼 때는 폰 오른쪽 바깥의 `● 녹화 중 [정지]` 막대 (영상엔 안 찍힘) → mp4 저장
- **안드로이드 크롬**: 화면 공유 허용 → "화면을 누르면 녹화 시작"을 한 번 더 누르면 전체화면으로 바뀌고 시작.
  끝낼 때는 **뒤로가기**(전체화면 나가기) → webm 저장 (안드로이드 크롬의 mp4 녹화는 프레임이 깨져서 webm 으로)
- 폰 화면이 좁아(폭 500 미만) 아래 버튼이 안 보이면 🔔 → 기본 → 화면 녹화
- 녹화 중 **마우스 포인터**: 폰 위에선 진짜 포인터 대신 가짜 포인터가 보임 — 내 눈엔 보이고 영상엔 안 찍힘
  (크롬 Element Capture. 지원 안 하는 브라우저면 진짜 포인터 그대로)
- **iPhone** 프레임이면 녹화 중 다이나믹 아일랜드 왼쪽에 빨간 점 (진짜 아이폰처럼, 영상에도 찍힘)

## 🔔 관리 패널 (홈 오른쪽 위 종 버튼)

화면은 보기 전용이고 **바꾸는 건 전부 여기서** 버튼과 숫자 입력으로 합니다.

- **기본**: 지금 프로필 + `프로필 바꾸기`, Galaxy ↔ iPhone, **캡쳐모드**(폰 테두리·아래 스위치 숨기기 — 화면 녹화/캡쳐용),
  **화면 녹화**(폰 아래 `● 녹화` 버튼과 같음. 폰 화면만 잘라 파일로 저장, 앱이 시작화면부터 다시 켜짐 — 아래 설명),
  시스템/라이트/다크, 이름·카드 끝 4자리,
  이 프로필 데이터를 `빈 상태로` / `예시 데이터로`
- **계좌**: 잔액 수정 / 다른 은행·증권사 계좌(은행선택 목록 60곳, 검색 가능) 추가·계좌번호 수정·삭제.
  추가한 계좌는 홈에 바로 생기고 눌러서 들어갈 수 있음
- **계좌 → 카드**: `이번달 쓴 돈` 직접 입력(또는 `자동 계산으로` = 이번 달 체크카드 거래 합계), `현금 돌려받을 기회 N건`
- **받는 분**: 이체할 상대 계좌(은행, 계좌번호, 예금주 이름) 등록·수정·삭제.
  이체 화면에서 계좌번호를 치면 여기 등록된 이름이 나옴 (진짜 은행의 "예금주 조회" 역할)
- **거래**: 계좌 고르고 금액·거래처·종류 고른 뒤 입금하기/출금하기. 최근 거래 삭제

**이체**: 홈의 `이체` 버튼 → 내 계좌 / 최근 이체 / `+ 계좌번호 직접입력`(은행선택 → 계좌번호) →
금액(키패드, +1만/+5만/+10만/전액) → 받는 분에게·나에게 표기 → 확인 → 완료. 내 계좌로 보내면 받는 쪽에도 입금 거래가 생깁니다.

데이터는 `server/`의 Express + SQLite 백엔드가 처리합니다. API 목록과 구조는 `SOLUTION.md` 12번.

### 이미지 에셋

저장소에는 무료 에셋(Microsoft Fluent 3D 이모지, MIT)만 들어 있습니다.
농협 로고, 카드 이미지, 티머니 로고, 캐릭터, 광고 사진 같은 **실제 이미지는 `src/assets/local/`에 넣으면**
자동으로 대신 쓰입니다. **지금은 저장소가 비공개라 이 폴더도 커밋돼 있어서 `git pull`만 하면 이미지까지 받아집니다.**
저장소를 다시 공개로 바꿀 땐 `.gitignore`의 주석을 풀어서 이 폴더를 빼야 합니다 (상표·광고 이미지).
은행/증권사 61곳 아이콘은 카카오뱅크 '은행선택' 화면 녹화·스크린샷에서 자동으로 잘라 씁니다 (없으면 대표색 동그라미):

```bash
# 녹화(맨 위 카카오뱅크~우체국이 보이는 21~22초), 스크린샷1(신협~현대차증권), 스크린샷2(삼성증권~토스증권)
python3 scripts/extract-bank-icons.py 은행선택.mp4 은행선택1.jpg 은행선택2.jpg   # ffmpeg, Pillow, numpy 필요
npm run build
```

```bash
# 화면 녹화 + 라이트모드 홈 스크린샷에서 자동으로 잘라내기 (ffmpeg 필요)
./scripts/extract-assets.sh 화면녹화.mp4 홈스크린샷.jpg [라이트모드녹화2.mp4] [배너스크린샷2.jpg]
npm run build
```

홈 화면 이미지(농협·AI 목표적금·카드·티머니 아이콘, 배너 그림 3개, 바로가기 4개, 아래 광고)는
**스크린샷**(720px, 녹화보다 1.5배 선명)에서 다시 자릅니다. 바깥 배경만 투명하게 따서(누끼) 라이트/다크 둘 다 씁니다:

```bash
python3 scripts/extract-screenshots.py --home 라이트_홈.jpg --dark 다크_홈.jpg --bottom 홈_아래.jpg \
  --banner-mcard 배너1.jpg --banner-pcbang 배너2.jpg --banner-friday 배너3.jpg      # Pillow, numpy 필요
python3 scripts/extract-bank-icons.py 은행선택.mp4 은행선택_중간.jpg 은행선택_아래.jpg 은행선택_맨위.jpg
```

이미 만들어 둔 에셋 묶음(zip)이 있으면 `src/assets/local/`에 풀고 `npm run build` 하면 됩니다.
