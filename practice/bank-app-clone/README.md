# 은행 앱 클론코딩 연습

학습 목적의 프론트엔드 클론코딩 연습 프로젝트입니다. 실제 서비스의 이름/로고/코드는 쓰지 않고
화면 구조와 UX 패턴만 참고해서 React로 다시 만들어봅니다. 데이터는 전부 가짜(mock)입니다.

## 시작하기

```bash
npm install
npm run dev
```

## 진행 방법

`SPEC.md`에 화면별 요구사항이 정리되어 있습니다. `src/components/*.tsx`와
`src/pages/*.tsx`에 있는 `TODO` 부분을 채우면서 진행하세요.

라우팅, 타입, mock 데이터는 이미 연결되어 있으니 `npm run dev`로 바로 확인하면서
작업할 수 있습니다.

## 스택

- Vite + React + TypeScript
- react-router-dom
