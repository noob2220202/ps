# 은행 앱 클론코딩 (학습용)

화면 녹화 영상을 프레임 단위로 분석해서 화면 구성, 색상, 애니메이션, 광고, 로딩 순서까지
그대로 재현한 React 클론입니다. 비상업적 학습 목적이며 상표권은 각 소유자에게 있습니다.

## 실행

Node **22.13 이상** 필요 (내장 SQLite 사용).

```bash
npm install
npm run dev        # 카카오뱅크: API 서버 + 화면 동시 실행 → http://localhost:5173  (?skip 붙이면 스플래시 생략)
npm run dev:nh     # NH 콕뱅크:  → http://localhost:5174 (API 8788)
npm run dev:hana   # 하나원큐:   → http://localhost:5175 (API 8789)
npm run dev:ibk    # i-ONE Bank: → http://localhost:5176 (API 8790)
npm run dev:kbank  # 케이뱅크:   → http://localhost:5177 (API 8791)
npm run dev:kbank2 # 케이뱅크 + 녹화 인트로: → http://localhost:5178 (API 8792)
npm run dev:ibk2   # i-ONE Bank + 녹화 인트로: → http://localhost:5179 (API 8793)
npm run dev:kakao2 # 카카오뱅크 새 녹화(아이폰) + 녹화 인트로: → http://localhost:5180 (API 8794)
npm run dev:toss   # 토스(갤럭시 · 다크 고정): → http://localhost:5181 (API 8795)
npm run dev:allone # NH올원뱅크(아이폰) + 녹화 인트로: → http://localhost:5182 (API 8796)
```

서버 하나가 화면과 API를 같이 줍니다. 포트 변경은 `PORT=8080 npm start`.
**서버 하나는 앱 하나만** 엽니다: `npm start` = 카카오뱅크(기본 9101, 데이터 `server/data/`),
`npm run start:nh` (= `APP=nh`) = NH 콕뱅크(기본 9103, 데이터 `server/data-nh/`),
`npm run start:hana` (= `APP=hana`) = 하나원큐(기본 9105, 데이터 `server/data-hana/`),
`npm run start:ibk` (= `APP=ibk`) = IBK기업은행 i-ONE Bank(기본 9107, 데이터 `server/data-ibk/`),
`npm run start:kbank` (= `APP=kbank`) = 케이뱅크(기본 9109, 데이터 `server/data-kbank/`),
`npm run start:kbank2` (= `APP=kbank2`) = 케이뱅크 + 녹화 인트로(기본 9111, 데이터 `server/data-kbank2/`),
`npm run start:ibk2` (= `APP=ibk2`) = i-ONE Bank + 녹화 인트로(기본 9113, 데이터 `server/data-ibk2/`),
`npm run start:kakao2` (= `APP=kakao2`) = 카카오뱅크 새 녹화(아이폰) + 녹화 인트로(기본 9115, 데이터 `server/data-kakao2/`),
`npm run start:toss` (= `APP=toss`) = 토스(갤럭시 · 다크 고정, 기본 9117, 데이터 `server/data-toss/`),
`npm run start:allone` (= `APP=allone`) = NH올원뱅크(아이폰) + 녹화 인트로(기본 9119, 데이터 `server/data-allone/`). 프로필 목록부터 전부 따로입니다.
데이터는 `server/data/`(SQLite)에 저장되고 커밋되지 않습니다. 프로필 목록은 `app.db`, 프로필별 은행 데이터는 `profiles/<id>.db`.
폴더째 지우면 예시 데이터의 "홍길동" 프로필 하나로 다시 시작. 예전 버전의 `bank.db`가 있으면 첫 프로필로 자동으로 옮겨집니다.

PC 브라우저에서는 폰 프레임 안에, 폰(폭 500px 이하)으로 열면 전체 화면으로 보입니다.

**갤럭시 / 아이폰 전환**: 프레임 아래 스위치를 누르거나 주소에 `?os=ios` / `?os=android`.
**라이트 / 다크**: 기본은 폰(시스템) 설정을 따름. 스위치나 `?theme=light` / `?theme=dark`로 고정.
아이폰으로 접속하면 자동으로 아이폰 버전. 아이폰 버전은 iOS 27 Liquid Glass 탭바, 다이내믹 아일랜드,
push 화면 전환, 왼쪽 가장자리 스와이프 뒤로가기가 들어가 있습니다.

## 👤 프로필 (넷플릭스처럼)

접속하면 먼저 **"누구의 은행을 열까요?"** 화면이 나옵니다. 프로필마다 계좌·거래내역·받는 분과
기기(Galaxy/iPhone)·테마(라이트/다크) 설정이 따로 저장돼서, 고르면 그 프로필이 마지막으로 쓰던 상태로 열립니다.

- `+ 프로필 추가`: 이름·아바타·색 고르기. 새 프로필은 **카카오뱅크 통장 0원만 있는 빈 상태**로 시작 (최대 5개)
- `프로필 관리`: 이름·아바타 수정, 삭제 (삭제하면 그 프로필의 데이터도 지워짐)
- 새 탭/창으로 들어올 때마다 다시 고름. 쓰던 중에 바꾸려면 🔔 → 기본 → `프로필 바꾸기`

## 🔑 로그인 · 계정 (은행마다 따로)

접속하면 로그인부터. 계정은 **관리자가 만들어 줌** (회원가입 없음). 카카오뱅크(9101)·콕뱅크(9103)·하나원큐(9105)·i-ONE Bank(9107)·케이뱅크(9109)·kbank2(9111)·ibk2(9113)·kakao2(9115)·토스(9117)·올원뱅크(9119)는 계정도 따로입니다.
- 계정마다 프로필(누구의 은행을 열까요?)이 여러 개, 프로필마다 은행 데이터가 따로
- 이용 기간: **1일 / 7일 / 30일 / 영구** — 계정을 만든 순간부터 줄어듦. 끝나면 로그인이 막히고(쓰던 중이면 로그인 화면으로),
  관리자가 연장하면 데이터 그대로 다시 사용
- **관리자**: 서버를 처음 켤 때 `admin` 계정이 생기고 비밀번호는 서버 로그와 `server/data/admin-password.txt`
  (앱마다 `server/data-nh/` · `data-hana/` · `data-ibk/` · `data-kbank/` · `data-kbank2/` · `data-ibk2/` · `data-kakao2/` · `data-toss/` · `data-allone/` 의 `admin-password.txt`)에 남음. 미리 정하려면 `ADMIN_PASSWORD=... npm start`.
  비밀번호를 바꾼 뒤엔 그 파일은 지워도 됨 (개발 서버 `vite` 는 `server/` · DB · 이 파일을 내주지 않게 막아 둠 — `vite.config.ts` 의 `fs.deny`)
  admin 으로 로그인 → 프로필 고르기 아래 `계정 관리` → 계정 만들기 / 연장(+1일·+7일·+30일·+영구) / 정지 / 비밀번호 바꾸기 / 삭제
- 예전에 있던 프로필은 관리자 계정 것으로 옮겨짐
- 로그아웃: 프로필 고르기 아래, 또는 🔔 → 기본

## 🟢 NH 콕뱅크 (두 번째 앱)

포트 9103(`npm run start:nh`)으로 들어가면 프로필 고르기 → 콕뱅크 다크 화면으로 열립니다 (간편비밀번호 로그인은 건너뜀).
카카오뱅크(9101)와 프로필·계좌·받는 분이 전부 따로입니다.

- 시작 화면 → **일반 홈**(다크): 큰글 스위치·MY·검색·알림·메뉴 / `NH농협 · 다른금융` 탭, `전체계좌 >` /
  계좌 카드(계좌가 여러 개면 옆으로 넘김, 🔒 잔액 숨기기, `거래내역 | 송금`) / `등록계좌` / 콕추천(가운데 카드가 커지는 가로 카드) /
  광고 배너 9개(3초마다 넘어감, ⏸) / 금융상품(적금 카드 4장, 타일 4개) / 마이데이터 / 아래 탭바.
  아래로 내리면 위 계좌 영역이 작은 카드(번호 ⌄, 잔액 `[송금]`)로 접혀 붙고, 탭바 대신 ↑ 버튼
- **라이트/다크 모드**: 폰(브라우저) 설정을 따르고, 🔔 → 기본 → 테마에서 시스템/라이트/다크로 고정.
  라이트 색은 라이트모드 녹화에서 화면마다 잰 값 (강조색이 보라가 아니라 청록)
- **콕송금**: 은행선택(은행/증권사 탭) → 계좌번호(키패드에 `콕`) → "얼마를 보낼까요?"(+1만/+5만/+10만/+100만/전액, 한글 금액,
  1일 송금 잔여한도 100만원) → 받는계좌·내계좌 표시 → 확인(거래메모) → 6개월간 안 보낸 분이면 "한번 더 확인" 시트 → 완료.
  아래 `최근송금 / 내계좌 / 자주쓰는` 목록에서 바로 고를 수도 있음. 받는 분은 카카오뱅크처럼 🔔 → 받는 분에 먼저 등록
- **전체계좌 조회**(홈 ☰ / 내계좌조회, `넓게` 스위치, `+ 농협계좌 등록`), **계좌별 거래내역**(계좌선택 시트, 입금/출금 조건),
  **거래 상세**(거래메모 저장, 입금은행·계좌 복사, `동일내역 송금` = 같은 계좌로 다시 보내기)
- 🔔 관리 패널은 홈의 종 버튼 (콕뱅크 색으로, 농협 관련만):
  - **계좌**: 계좌마다 이름(자립예탁금 등)·잔액·계좌번호 수정, `농협 계좌 추가`(이름, 13/14자리 번호, 시작 잔액 — 다른 은행은 추가 안 됨), 삭제
  - **받는 분**: 콕송금으로 보낼 상대 계좌 (하나은행 등 다른 은행으로도 보낼 수 있어서 은행은 전부 고를 수 있음)
  - **거래**, **기본**(프로필, 기기, 캡쳐모드, 녹화, 이름, 빈 상태로/예시 데이터로). 카카오뱅크 전용(테마, 카드, 세이프박스)은 없음

**실제 앱과 픽셀 단위로 맞춤** (스크린샷 720px·녹화 480px 기준):
Galaxy 폭 384dp(프레임 384 × 853.33), 글꼴 Pretendard, 색·크기·위치·글자 굵기, 0.5dp 선,
화면 전환(안드로이드 80/100ms 페이드), 시트 열림/닫힘 곡선, 버튼 누르면 "어둡게 + 점 3개" 로딩(그 아래에서 다음 화면으로 바뀜)까지.
남는 차이는 가짜 이름·계좌번호 글자, 상태바 시계 정도입니다.

## 💚 하나원큐 (세 번째 앱)

포트 9105(`npm run start:hana`)로 들어가면 로그인 → 프로필 고르기 → 시작화면(하나 1Q 원큐) → 하나원큐 홈.
라이트/다크 둘 다 실제 앱 녹화·스크린샷(2026-10-30)에 맞춰 그렸고, 폰 설정을 따르거나 스위치로 고를 수 있어요.

- **홈**: 대표계좌(입출금 · 통장 이름 · 번호 · 잔액 숨김, 계좌가 여럿이면 `< 1 / n >` 화살표나 옆으로 밀어서 넘김) → 가져오기/보내기 → 전체계좌 → 배너 10장(자동 넘김, 멈춤) →

## 🔵 토스 toss (갤럭시 · 다크 고정)

포트 9117(`npm run start:toss`)로 들어가면 로그인 → 프로필 고르기 → 시작화면(파란 토스 심볼) → 토스 홈.
토스 앱(토스 홈 · 토스뱅크 통장 · 송금 · 증명서 · 소비 · 자산)을 **안드로이드 갤럭시 화면 녹화 두 개**(480 × 1066px = 384 × 853.33dp, 1dp = 1.25px, 다크 모드)에 맞춰 새로 만든 서버예요.
녹화 기기 그대로 **갤럭시 · 다크로 고정**이라 `Galaxy/iPhone` · `라이트/다크` 스위치와 🔔 → 기본의 기기 · 테마가 없고, 프로필에 저장된 기기 · 테마도 안 봐요. **녹화 인트로는 없어요**.
데이터·계정은 따로 쓰고(`server/data-toss/`, 로그인 쿠키 `bank_sid_toss`), 예시 데이터는 토스 전용 `seedTossExample()`(`server/toss-seed.mjs`)예요.
개발은 `npm run dev:toss` → http://localhost:5181 (API 8795). 다른 앱 화면은 하나도 바뀌지 않았어요 — 토스 코드는 전부 `src/toss/` · `server/toss-*.mjs` 에 있거나 토스에서만 켜지는 조건 안에 있어요.

- **계좌 → 계좌 지급정지** (카카오뱅크, 연습용): `켜기` 면 이체는 보통처럼 받는 분 → 금액 → 표기 → 확인 시트까지 가고,
  마지막 `이체하기` 를 누르면 서버가 막고(403 `ACCOUNT_SUSPENDED`) '고객센터로 문의해주세요.' 팝업
  (명의도용/금융사기·대포통장 의심으로 이용 제한 안내, 오류코드 보기, AI 상담챗봇, 확인)이 떠요. 돈은 빠지지 않아요. 팝업 맨 위에는 늘 빨간
  '연습용 화면 · 실제 이용 제한 아님' 표시가 같이 나와요 (끄는 설정 없음)
- **계좌 → 카드**: `이번달 쓴 돈` 직접 입력(또는 `자동 계산으로` = 이번 달 체크카드 거래 합계), `현금 돌려받을 기회 N건` (케이뱅크는 홈 'ONE n월 쓴 돈' 에 쓰이는 이번 달 쓴 돈만)

- **거래**: 계좌 고르고 금액·거래처·종류 고른 뒤 입금하기/출금하기. 최근 거래 삭제

**이체**: 홈의 `이체` 버튼 → 내 계좌 / 최근 이체 / `+ 계좌번호 직접입력`(은행선택 → 계좌번호) →

### 이미지 에셋

실제 그림(은행 로고 · 카드 · 캐릭터 · 광고 사진 등)은 `src/assets/local/<이름>.png|svg|jpg` 에 있고(테마별은 `<이름>.light|dark.png`),
없으면 무료 에셋(Microsoft Fluent 3D 이모지, MIT)이나 대표색 동그라미로 대신 그립니다.
**지금은 저장소가 비공개라 이 폴더도 커밋돼 있어서 `git pull`만 하면 이미지까지 받아집니다.**
저장소를 다시 공개로 바꿀 땐 `.gitignore`의 주석을 풀어서 이 폴더를 빼야 합니다 (상표·광고 이미지).

**에셋 검수 (2026-11)**: 화질 · 누끼 · 여백을 다시 봐서 거의 다 새로 만들었어요 — 화면 1px 당 그림 3px 이상, 바탕 넷(체크 · 검정 · 흰 · 앱 바탕)에서
테두리 · 찌꺼기 없이, 파일은 잉크 상자로 자르고 CSS 자리를 그만큼 옮겨 화면 위치는 그대로. 은행 로고 61곳은 원이 꽉 찬 150px
(IBK · 신협 · 우체국 · 신영 · BNP 는 벡터로 다시 그림), 티머니 · 앨범 로고 · 콕뱅크 탭 · 케이뱅크 아이콘 여럿은 SVG.
방법과 스크립트는 `SOLUTION.md` 24장 · `scripts/asset-fixes/`. **예전 자르기 스크립트(아래)는 기록용** — 다시 돌려도 이미 있는 파일은 건너뛰고
(`scripts/keep_assets.py`), 정말 덮어쓰려면 `--force`(셸 스크립트는 `FORCE=1`). 덮어쓰면 옛 그림(여백 · 흰 테)이 되고 자리도 어긋나요.

은행/증권사 61곳 아이콘을 처음 만든 방법 — 카카오뱅크 '은행선택' 화면 녹화·스크린샷에서 잘라 씀:

```bash
# 녹화(맨 위 카카오뱅크~우체국이 보이는 21~22초), 스크린샷1(신협~현대차증권), 스크린샷2(삼성증권~토스증권)
python3 scripts/extract-bank-icons.py 은행선택.mp4 은행선택1.jpg 은행선택2.jpg   # ffmpeg, Pillow, numpy 필요
npm run build
```

```bash
# 화면 녹화 + 라이트모드 홈 스크린샷에서 자동으로 잘라내기 (ffmpeg 필요)
./scripts/extract-assets.sh 화면녹화.mp4 홈스크린샷.jpg [라이트모드녹화2.mp4] [배너스크린샷2.jpg]
npm run build
```

홈 화면 이미지(농협·AI 목표적금·카드·티머니 아이콘, 배너 그림 3개, 바로가기 4개, 아래 광고)는
**스크린샷**(720px, 녹화보다 1.5배 선명)에서 다시 자릅니다. 바깥 배경만 투명하게 따서(누끼) 라이트/다크 둘 다 씁니다:

```bash
python3 scripts/extract-screenshots.py --home 라이트_홈.jpg --dark 다크_홈.jpg --bottom 홈_아래.jpg \
  --banner-mcard 배너1.jpg --banner-pcbang 배너2.jpg --banner-friday 배너3.jpg      # Pillow, numpy 필요
python3 scripts/extract-bank-icons.py 은행선택.mp4 은행선택_중간.jpg 은행선택_아래.jpg 은행선택_맨위.jpg
```

이미 만들어 둔 에셋 묶음(zip)이 있으면 `src/assets/local/`에 풀고 `npm run build` 하면 됩니다.
