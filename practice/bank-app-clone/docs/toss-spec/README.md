# 토스(toss) 작업 설계 문서 (작업 중 · 이어하기용)

녹화 두 개를 분석해 만든 설계 문서. 녹화 속 개인정보(이름 · 계좌번호 · 금액 · 가게)는 들어 있지 않음 (자리표시 `<NAME_A>` 같은 것과 지어낸 예시 데이터만).
클론은 **성인 계정**으로 보임: 원본 녹화의 연령 전용 상품은 성인용으로 바꿈 (홈 소비 카드 둘째 줄 = 신용카드 '{D}일 낼 카드값', 예시 데이터 = plan.md §2.3, 목록과 출처 = SOLUTION 27장 '성인 계정').

- `plan.md` — 전체 계획 (결정 · 화면/주소 · 데이터 · 공용 부품 · 영역 나누기 · 확인 목록)
- `foundation.md` — 기반 작업이 실제로 만든 것 (nav/flow/ui 내보내기 · API 모양). plan.md 와 다르면 이쪽이 맞음
- `infra.md` · `home.md` · `account.md` · `transfer.md` · `cert.md` · `assets.md` — 영역별 측정값
