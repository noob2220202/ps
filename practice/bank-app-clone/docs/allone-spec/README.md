# NH올원뱅크(allone) 작업 설계 문서

아이폰 녹화 세 개(C1 · C2 · C3)를 분석해 만든 설계 문서. 녹화 속 개인정보(이름 · 계좌번호 · 금액 · 가게 · 홈 화면)는 들어 있지 않음
(자리표시 `<NAME_A>` 같은 것과 지어낸 예시 데이터만).

- `plan.md` — 전체 계획 (결정 · 화면/주소 · 로딩 시간표 · 데이터 · 공용 부품 · 영역 나누기 · 확인 목록). 영역 문서와 다르면 이쪽이 맞음
- `infra.md` — 서버 · 앱 등록 · 기기 틀(상태바 · 띠 · 섬) · 녹화 인트로 연결, 파일별 손댈 곳
- `launch.md` — 인트로(그린 아이폰 홈 화면) · 시작 화면 · PIN · 로그인 로딩
- `home.md` — 홈 · 정기점검 안내 · 전체메뉴 · 통합검색
- `account.md` — 거래내역조회 · 거래내역 상세
- `transfer.md` — 누구에게 · 얼마를 · 계좌 비밀번호 · 잔액채우기 · (지어낸) 이체 확인/완료

만들지 않는 것: 출금정지 안내, 이의제기, 휴대폰 본인인증, 신분증 · 모바일 신분증, 다른 앱 붙여넣기 허용 창.
