# 전역 토큰 (색 · 딤 · 스피너 · 토글 · 글꼴 역할)

여러 화면이 같이 쓰는 값만 모았다. 기계용 같은 내용은 [`tokens.json`](tokens.json)이다.
**요소별 정확한 값은 각 화면 스펙(`spec/<group>.json` 의 elements)이 우선한다.** 토큰은 기본값이고, 화면 스펙이 다른 값을 재면 그 값을 쓴다.
글꼴 자체(Pretendard Variable, 로드 방법, 숫자 정렬, 자간)는 [`font.md`](font.md).

## 1. 측정 방법과 주의

- **영상**: 늘 손잡이를 지운 `*-clean.mp4`. 기준 프레임은 `tools/woori_video.py ref` 규칙(구간 중앙값)으로 만든다. 아래 출처의 `#a–#b` 는 원본 프레임 번호(둘 다 포함)이다.
  다시 만들려면 `python3 tools/woori_video.py ref --video v1 --i0 '#1612' --i1 '#1627' --out tools/ref/font/hist.png` 처럼 한다
  (이 문서에 쓴 기준 프레임은 `tools/ref/font/` 에 있고, `tools/woori-textfit.cjs --selftest` 가 없으면 다시 만든다).
- **면 색**: 가장자리에서 6px 이상 떨어진 사각형의 **채널별 중앙값**. 표준편차가 0–1 레벨인 곳만 쓴다.
  - 영상은 **YUV 4:2:0** 이다. 색차가 2x2 화소마다 하나라서 경계 근처 2–3px 은 색이 번진다. 넓은 면의 가운데에서만 잰다.
  - 16px 매크로블록 경계에서 R 채널이 ±2 오르내리는 줄무늬가 있다(예: 홈 바탕 R 238/242). 중앙값이 이를 지운다.
  - 흰 바탕에 **이전 화면의 흔적 같은 옅은 선 무늬(최대 4레벨)**가 보인다. 화면마다 다르고 같은 화면을 두 영상에서 비교해도 상관이 없다(상관계수 0.05) → 앱이 그린 것이 아니라 코덱 잔상이다. 앱에는 그리지 않는다.
- **글자 색**: 잉크 상자에서 배경과 가장 먼 4% 화소의 평균(코어). 16dp 이상·굵기 600 이상이면 코어가 실제 색에 닿는다.
  14dp 이하나 얇은 글자는 코어가 실제보다 옅고, 색차가 흰 바탕과 섞여 **채도가 낮게(회색 쪽으로)** 찍힌다. 그래서 파란 글자는 굵은 글자 값으로 정했다.
  같은 글자도 v1 은 무채색 쪽, v2 는 푸른 쪽으로 2–3레벨 다르게 찍힌다(인코더 차이). 이 정도는 같은 색으로 본다.
- **1dp 선**: 1dp = 16/11 px 이라 선이 두 행에 걸쳐 찍힌다. 가로지르는 행들의 잉크 합을 16/11 로 나눠 "1dp 로 칠했을 때 같은 잉크가 되는 색"으로 적었다.
- **딤 알파**: 같은 면을 딤 전/후로 비교해 `α = 1 − 후/전`. 흰·파랑·연파랑 세 면에서 같은 값이 나와야 채택.
- 값의 반올림: 측정은 정수 RGB, 권장값은 측정값 그대로(두 영상·여러 화면 평균). 녹화 경로의 색 변환(BT.601 limited)을 거친 값이라 원래 앱 값과 ±1–2 다를 수 있지만, 답지는 **영상과 같은 색**이 목표이므로 측정값을 쓴다.

- 거래 행의 '11월 21일 · 11:02:40' 은 한 덩어리로 맞추면 0.33 이고 날짜(0.147)·시각(0.151)을 따로 맞추면 맞는다 → 가운데 점과 간격이 따로 배치된 요소다.
- 굵기는 400/500/600/700 만 나왔다. 홈 본문('다른 은행 계좌도 홈에서 확인할 수 있어요')은 14.75dp w500 ls +0.0125 로 나와 설계값이 15dp 일 가능성이 있다 — home 스펙에서 확인.

## 8. 남은 것

1. 파란 글자 두 값(blueText #1f67bd, deposit #2267be)이 같은 토큰인지 모른다(Δ4). 얇은 링크 글자는 화면 스펙에서 `--color` 를 주고 도구의 `inkScale`(≈1 이면 맞음)로 확인한다.
2. 진한 글자의 v1/v2 색차 차이(무채색 #353536 ↔ 푸른 #32353b)는 인코더 차이로 보고 하나(#33353a)로 묶었다.
3. 거래 상세 값의 크기·자간(14.75dp, −0.025em)은 0.5dp 단위로 떨어지지 않는다. tabular 의 설계값은 15dp −0.03em 근처일 수 있다 — history-detail 스펙에서 확인.
4. 다크 모드는 영상에 없다. 토큰은 라이트 값만 측정했다.
