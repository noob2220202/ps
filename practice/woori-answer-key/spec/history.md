## 0. 읽는 법

- 좌표: **frame px** = 영상 524x1280 화면 절대 좌표. **dp** = 설계 dp, y 는 **앱 뷰포트 기준**(화면 y − 31.333). 변환은 D1:
  가로 `x_dp = 180 + (x_px − 262.02)/1.45803`, 폭 `w_px/1.45803` · 세로 `y_dp = y_px × 0.6875 − 31.333`, 높이 `× 0.6875`.
- 글자: `font` = woori-textfit `best`(design 경로 크기·굵기·자간 + shot 경로 위치). json `dp` = line-height:1 상자(left, top(+translateY), advance, font-size),
  `inkBox` = 잉크 상자(frame px). md 의 "기준선" 은 앱 dp. 글꼴은 Pretendard Variable, 자간 0, proportional(spec/font.md).
- 상자: 둥근 사각은 부분 픽셀 맞춤(덮임 비율 모델, Nelder–Mead)으로 x·y·w·h·r 을 잰 값을 "맞춤"으로 적고, 설계 dp 는 그 값을 정수/0.5/⅓dp(기기px 격자)로 해석했다.
  ⅓ 이 붙은 세로 값(261.333 등)은 영상에서 실제로 기기px 1칸(⅓dp) 아래에 있는 것 — 앱 셸의 `translateY(0.333px)` 로 같은 줄에 온다(units.md 6.3).
- 시간: 원본 프레임 #번호와 pts(초). "시각 t 의 화면" = pts ≤ t 인 마지막 프레임. 곡선은 clean 프레임에서 흔들림 허용 없이 다시 맞췄다(D8, 3절).
- 마스크: 스피너 `224,590,76,76`, 오버레이 스크롤바 `512,46,12,1164`, 기본(상태바 `0,0,524,46` · 내비 `0,1210,524,70`).
- 토큰 이름은 spec/tokens.md. 2레벨 안이면 토큰 이름, 아니면 잰 값을 같이 적었다.

### 3.2 스켈레톤 반짝임 (`skeleton-shimmer`) — 한 번만

- 스켈레톤 첫 프레임 뒤 58–142ms(평균 ≈105)에 시작, **각 막대 안에서** 밝은 띠가 왼쪽→오른쪽(막대 폭 비례 — 모든 막대가 같은 위상).
- 띠 모양: 뒤쪽 0.36W 길이로 서서히 밝아지고 앞쪽 0.08W 에서 뚝 떨어지는 비대칭, 가장 밝은 곳 **+8 레벨**(#eff0f3 → ≈#f7f8fb, 흰색 α≈0.53). 살짝 기울어짐(위가 3–4px 앞섬).
- 가장 밝은 곳의 막대 안 위치(v2 5.668 기준 ms → 비율): 0→0.01, 33→0.26, 84→0.42, 108→0.59, 125→0.66, 142→0.78, 158→0.84, 175→0.92, 201→0.97 — 그 뒤 꼬리가 빠지며 밝기 7.9→2.6(201→310ms). 전체 ≈350ms. 5회 모두 같은 모양(v1 1차는 +100ms 에 시작해 250ms 에 0.93).
- 앱: 막대마다 `background: linear-gradient(90deg, transparent 0, rgba(255,255,255,.53) 36%, transparent 44%)` 를 `background-position` 으로 한 번 쓸기(곡선은 표본 재현, 근사 ease-out 계열). 반복 없음.

## 8. 가정 · 설계값 · 미확정

1. **설계값(영상에 없음)**: 기간 내 합계 펼침(D7 — 입금 합계·출금 합계 두 줄, 같은 상자 안, 14/500 라벨 + 14/600 금액 오른쪽 정렬, ⌄ 180° 회전 200ms; 숫자는 기간 안 거래 합), 상세조건조회 펼침, 직접입력, 이번달·6개월·1년 기간 줄(4.4), [초기화]·✕·딤 탭, "관리"·🔍·⌄·복사 탭, [모으기] 눌림, 시트 위 OS 뒤로.
2. 선택 칩 그림자 `0 1px 2px rgba(0,0,0,.06)` 은 근사 — 아래쪽만 3–6 레벨 어두운 것을 맞춘 값(렌더 대조 필요).
3. 스켈레톤 반경 4 와 5 는 구별 안 됨(4.5 로 적음). 반짝임 곡선은 근사 — 표본 재현 권장.
4. [이체]·[적용하기] 눌림의 크기 변화는 표본이 3–5장뿐(scale 0.99 근사). 언제 줄기 시작하는지(누른 뒤 vs 떼기 직전)는 두 회차가 서로 다른 해석을 허용 — 둘 다 "떼기 ≈50ms 전" 으로 맞는다.

6. 계좌 줄 글자는 실제 번호로 맞췄다(같은 자리수). 더미 숫자의 폭 차이만큼 복사 아이콘 x 가 움직인다(글자 끝 + 4dp).
