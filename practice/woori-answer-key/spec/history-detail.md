## 0. 읽는 법

- **좌표**: `box`/`inkBox` = frame px (524×1280, 화면 절대, 상태바 포함). `dp` = 설계 dp, y 는 **앱 뷰포트 기준**(CSS top, 화면 dp − 31.333). 변환 D1: `x_dp = 180 + (x_px − 262.02)/1.45803`, `y_dp = y_px × 0.6875 − 31.333`, 폭 `/1.45803`, 높이 `×0.6875`. spec-to-dp 가 frame→D1 과 설계 dp 를 비교한다(444개, 최대 차이 0.352dp). 모양(선·버튼·알약·✕)은 잰 값이 `box`, 설계값이 `dp` — 페이지·머리·하단 바처럼 영상에서 경계가 안 보이는 것만 `boxFromDesign`.
- **기준 프레임**: `tools/ref/history-detail/<state>.png` (clean 영상 중앙값, `python3 tools/ref.py --name history-detail/<state> --video v1 --i0 '#a' --i1 '#b'`). 손잡이 자리는 잔여 1–2레벨(woori_edge 한계)만 남는다.
- **측정**: 선·버튼·알약·꺾쇠·✕ = 휘도 모형 맞춤(모양을 frame px 격자에 6배 표본으로 그려 L1 최소; 둥근 사각·선분·둥근 끝), 가로선 = 잉크 합(1dp 환산)과 중심. 색 = 넓은 면 중앙값, 가는 획은 모형 덮임 비율로 채널별 맞춤. 대비가 낮은 면(#e3f1fd / 흰)은 ±0.2px 흔들린다.
- **글자**: `tools/woori-textfit.cjs` 의 `best`(= 폰 경로 설계 크기·굵기·자간 + DSF 16/11 셸 위치, D10). 표의 `L/T` 는 `position:absolute; line-height:1` 상자의 left/top(앱 dp), `+0.25px` 는 `transform: translateY(0.25px)`. 오차 = design(fitError, 폰 경로) / shot(스크린샷 경로). 이름·계좌는 영상 글자로 맞추고(결과는 스크래치에만) 스펙에는 더미를 쓴다.
- **시간**: VFR — 시각 t 의 화면 = pts ≤ t 인 마지막 프레임. 곡선은 프레임 pts 그대로, 시각 흔들림 허용 없이 맞췄다(D8). 시작 시각은 "앞 정지 프레임 pts < 시작 ≤ 첫 움직임 프레임 pts" 창 안에서만 받아들였다. rms 단위는 frame px(불투명도는 α).
- **더미**: 입금 상대 **한지호**, 출금 상대/받는 분 **정우진**(목록 표시 이름 **농협정우진**), 지역농축협 **12345652789012** (privacy.json). 더미 글자는 폭·모양이 실제와 달라 그 상자를 `privacyMask`(json) 로 적고 shots.d 의 `maskAdd` 로 비교에서 뺐다.
- **주인(D12)**: 거래 상세 = 이 그룹. 뒤 목록·가운데 스피너·일반 페이지 머리 = history. 탭바·홈 = home. 이 화면은 일반 페이지 머리(‹)가 아니라 상세 전용 머리(제목 가운데 + ✕)다.

## 3. 전환 · 애니메이션

움직이는 것은 세 가지다: **상세 페이지**(머리·내용·하단 바가 한 덩어리 — 바도 같이 움직인다), 페이지 **아래 목록에 덮이는 흰 막**(WooriNav push+veil 의 막과 같은 것), 출금형의 **행 끼워 넣기**. 눌림 효과는 [확인]만 있다.

측정 방법: 프레임마다 `F − B = A_s·(255 − B) + A_p·pg(dy)·(S − B − A_s(255 − B))` (B = 목록 정지 화면, S = 상세 기준 그림을 dy 만큼 내린 것, pg = 페이지가 덮는 자리, 휘도·σ1.2–2.5 흐림·가로 4칸 평균)를 dy 0.05px 격자에서 최소제곱으로 풀었다(스크립트 SP/spec-work/history-detail/scripts/trans4.py·closefit.py). 페이지 내용의 불투명도는 움직임 흐림 때문에 5–15% 낮게 나와서, 열기의 불투명도는 "흰 바탕이 목록을 가린 정도"(a_bg) 로 쟀다. 표의 dy 는 frame px(오른쪽 dp).

- **상세 페이지**: `translateY 0 → +96dp(140px)` cubic-bezier(0,0,0.2,1) **240ms**(rms 2.74px, critic 이 #3750 을 고친 뒤) + `opacity 1 → 0` cubic-bezier(0,0,0.2,1) **260ms**(rms 0.023), 같은 시작(두 곡선의 맞춘 시작 차 0–8ms). 끝나면 페이지를 뗀다.

## 8. 가정 · 설계값 · 미확정

1. **값 열 15dp**(5.2) — font.md 5·6절과 tokens.md 8-3 의 '14.75dp/−0.025em' 는 이 결론으로 바꿔야 한다(그 문서들은 platform/font 주인이 고친다).
2. **흰 막(veil)**: 닫기는 잘 잰 값(0.69 → 0, linear 271ms, +30ms). 열기 쪽 막 곡선(linear 330ms 0→0.69)은 프레임 몇 장뿐이라 **설계값**. 막이 목록(history) 위에 그려지는지, 상세 컨테이너의 뒷면인지는 화면에서 구별되지 않는다 — WooriNav 의 veil 과 같은 층으로 구현하길 권한다.
3. **출금형 숨은 상자**(`hidden-outline-box`): 검색 줄 아래 46dp 근처에서 시작하는 둥근 테두리 상자의 윗변만 보인다(1093.5–1101.5px). 내용은 하단 바에 가려 영상에 없다 — 다시 이체 같은 외곽선 버튼으로 추정(**설계값**, 높이·글자 모름). 입금형과 출금 첫 그림에는 없다.
