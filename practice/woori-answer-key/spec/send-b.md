## 0. 읽는 법

- **좌표**: `box`/`inkBox` = frame px (524×1280, 화면 절대, 상태바 포함). `dp` = 설계 dp, y 는 **앱 뷰포트 기준**(CSS top, 화면 dp − 31.333). 변환 D1: `x_dp = 180 + (x_px − 262.02)/1.45803`, `y_dp = y_px × 0.6875 − 31.333`, 폭 `/1.45803`, 높이 `×0.6875`. spec-to-dp 가 frame→D1 과 설계 dp 를 비교한다(2264개, 0.5dp 넘는 것은 저대비 면 폭 6개 — dpLoose + 이유).
- **기준 프레임**: `tools/ref/send-b/<state>.png` (clean 영상 중앙값, `python3 tools/woori_video.py ref --video vN --i0 '#a' --i1 '#b'`). 두 영상에 다 나온 상태는 다른 영상 판을 `<state>-v2.png`(또는 `-v1`)로 만들어 json `keep.alt` 와 shots.d 에 넣었다.
- **측정**: 상자 = 휘도 50% 가장자리(연속 좌표 — 화소 k 는 [k, k+1), 둥근 모서리를 피해 변 가운데 40%), 모서리 반지름 = 위끝 아래 행들의 경계를 원에 맞춤, 원(로고) = 템플릿 맞춤(배율·위치 탐색), 선 = 잉크 합. 저대비 면(#f6f7fa·#eff0f3 / 흰)은 ±0.3px 흔들린다.
- **글자**: `tools/woori-textfit.cjs` 의 `best`(= 폰 경로 설계 크기·굵기·자간 + DSF 16/11 셸 위치, D10). 표의 `L/T` 는 `position:absolute; line-height:1` 상자의 left/top(앱 dp), `+0.25px` 는 `transform: translateY(0.25px)`. 오차 = design(fitError, 폰 경로) / shot(스크린샷 경로). 한 글자짜리(숫자 키)의 자간 값은 의미 없어 0 으로 적었다. 이름·계좌는 영상 글자로 맞추고(결과는 스크래치에만) 스펙에는 더미를 쓴다.
- **시간**: VFR — 시각 t 의 화면 = pts ≤ t 인 마지막 프레임. 전환 곡선은 프레임 pts 그대로, 시각 흔들림 허용 없이 맞췄다(D8). 두 영상에 같은 전환이 있으면 곡선·길이를 공통으로, 시작만 영상마다 따로 맞췄다(joint). rms 단위는 frame px(불투명도는 α).
- **더미**: 받는 분 정우진 · 내 계좌 1002-123-456789 · 지역농축협 12345652789012 · 카카오뱅크 3333123456789 (privacy.json). 더미 글자 폭이 실제와 달라 그 글자 상자는 json `keep.privacyMask` 로 적고 shots.d 의 maskAdd 에 넣었다. 이름 뒤에 붙는 글자("님 계좌로", "님에게")와 ⌄ 의 x 는 이름 폭에 따라 바뀐다(inline 배치).
- **critic(반박 검증) 고침**: 이 문서는 critic 단계가 다시 재서 고친 판이다 — 고친 곳은 `(critic)` 로 표시, 근거·숫자는 스크래치 `critic-send-b.md`. 요지: 정지가 아니던 기준 구간 7곳, 주 버튼 눌림 scale 0.95(새 3.13), 스크롤 영역 1기기px 이동(3.1 S6), ⚠ 색·삼각형 튕김, 확인 머리 받는 로고 y, 통장표기 묶음 opacity 곡선.
- **주인(D12)**: 금액 키패드 · 계좌 비밀번호 시트(섞인 키패드) = **send-b(이 그룹)**. ‹·취소(일반 페이지 머리)·✕·⌄·›·공통 스피너 = history, 은행 로고 = send-a(banks.json), 완료 페이지 = done.

## 8. 가정 · 설계값 · 미확정

1. **비밀번호 키패드 섞는 규칙**: 관찰 2번 모두 9 가 마지막 줄 가운데 — 0–8 만 섞는다고 봤다(추정). PRNG·시드는 설계값. 누른 키 칸(#e6eaee, 97.2×56, r≈5.3)은 한 프레임만 보여 크기는 ±1px.
2. **비밀번호 시트 열림·닫힘 애니메이션·딤 곡선**: 보안 검은 화면에 가려 녹화에 없다. 열림은 중복 경고 시트와 같은 곡선(easeOutCubic 245ms + 딤 linear 305ms, 딤 끝값 0.4392)으로 설계, 닫힘은 영상대로 한 프레임.
3. **물결 중심**: 실제 누른 자리(영상에서 버튼 오른쪽 절반 x≈300–360px 로 추정, 원 맞춤이 불안정해 정확히 모름). 반지름 속도 1.65dp/ms·덮개 α 0.13 은 표본 4–5프레임에서.
4. **통장표기 묶음 시작 거리 48dp**: 62–73px 범위에서 rms 차 0.01 — opacity 시작과 맞는 값으로 골랐다. 44dp(64px)도 거의 같다.
5. **키패드 높이 값**: [확인] 52.333dp(157기기px), 칩 28.667dp, 시트 높이 426.667 — 1/3dp 값은 기기px 정수로 보고 그대로 적었다(웹 코드는 소수 dp 그대로).
6. ~~로고 위치 0.7dp 차~~ (critic 풀림): 원 가장자리(밝기 50%)로 재면 두 로고 모두 top 83.0 (가운데 y 106.92–107.03, 네 판). 0.7dp 는 템플릿 맞춤 치우침이었다.
7. **확인 화면 행 간격**: 정보 상자 행 기준선 327.25 / 362 / 396(간격 34.75 / 34) — 기준선이 기기px 행에 붙어 ±0.33. 설계는 34.33(103기기px) 으로 볼 수 있다.
8. **두 줄 제목의 줄 높이**: 중복 경고 31dp, 확인 30dp (기준선 간격). line-height 는 이 값으로.
9. **이체 확인 제목 파랑 #146bd6**: 토큰 `--woori-blue-text`(#1f67bd)·입금 파랑(#2267be)과 다른 밝은 파랑 — 22/700 큰 글자 코어라 실제 색에 가깝다. tokens.md 8절 1번 질문(파란 글자 두 값)과 별개.
10. **오버레이 스크롤바**: WebView 기본으로 보고 마스크. 앱이 그리려면 2.7dp 폭 #a09ea3, 0.8s 뒤 0.16s 페이드.
11. **영상에 없는 것(설계)**: ← · 00 · 0 · 빠른 금액 칩 동작, [아니요]/✕ 로 중복 경고 닫기, 비밀번호 틀림, 전체삭제, 통장표기 편집, 더보기 펼침, 추가이체, ‹/취소.

14. (critic) **주 버튼 눌림 scale 0.95** 는 history 4.2(0.99)·send-a 의 주 버튼과 같은 공통 효과로 본다 — 주인(공통 버튼)을 정해 한 곳에 적을 것. 곡선은 기기px 계단 때문에 ease-in-out / easeInOutSine / linear 가 같은 rms.
