## 0. 읽는 법

- **좌표**: `box`/`inkBox` = frame px (524×1280, 화면 절대, 상태바 포함). `dp` = 설계 dp, y 는 **앱 뷰포트 기준**(CSS top, 화면 dp − 31.333). 변환 D1: `x_dp = 180 + (x_px − 262.02)/1.45803`, `y_dp = y_px × 0.6875 − 31.333`, 폭 `/1.45803`, 높이 `×0.6875`. spec-to-dp 가 frame→D1 과 설계 dp 를 비교한다(이 스펙 1960개, 최대 차이 0.477dp).
- **기준 프레임**: `tools/ref/send-a/<state>.png` (clean 영상 중앙값, `python3 tools/woori_video.py ref --video vN --i0 '#a' --i1 '#b'`). v2 교차 확인용은 `tools/ref/send-a/_x/`.
- **측정**: 상자 = 휘도 가장자리 면적법(가장자리 ±4px, 둥근 모서리를 피해 변 가운데), 원 = 지름 방향, 가로선 = 잉크 합(2dp 로 환산), 모서리 반지름 = 대각선 50% 지점. 대비가 낮은 면(#eff0f3·#f6f7fa / 흰)은 코덱 고리 때문에 ±0.3px 흔들린다.
- **글자**: `tools/woori-textfit.cjs` 의 `best`(= 폰 경로 설계 크기·굵기·자간 + DSF 16/11 셸 위치, D10). 표의 `L/T` 는 `position:absolute; line-height:1` 상자의 left/top(앱 dp), `+0.25px` 는 `transform: translateY(0.25px)`. 오차 = design(fitError, 폰 경로) / shot(스크린샷 경로). 이름·계좌는 영상 글자로 맞추고(결과는 스크래치에만) 스펙에는 더미를 쓴다.
- **시간**: VFR — 시각 t 의 화면 = pts ≤ t 인 마지막 프레임. 전환 곡선은 프레임 pts 그대로, 시각 흔들림 허용 없이 맞췄다(D8). rms 단위는 frame px(불투명도는 α).
- **더미**: 받는 분 정우진 · 지역농축협 12345652789012 · 카카오뱅크 3333123456789 (privacy.json). 더미 글자 폭이 실제와 달라 그 상자는 `privacyMask`(json) 로 따로 적고, shots.d 의 mask 에 더했다.
- **주인(D12)**: ‹(일반 페이지 머리)·스피너 = history, 금액 페이지 이후 = send-b. 금융회사 로고 21개 + banks.json + 삼성 키보드 = send-a(이 그룹).

### 3.2 계좌번호 페이지 push + 흰 베일

- 새 페이지 `translateX(100% → 0)` **easeOutCubic (0.33,1,0.68,1) 322ms**, 곡선 시작 63.742 (탭 ≈63.740). 아래 페이지는 제자리, 그 위에 흰 베일 `opacity 0 → 0.8` **linear 326ms** (시작 +30ms). 베일은 계좌번호 페이지가 닫힐 때까지 0.8 로 남는다.

- **그리는 법 (critic 확인)**: 이 9개는 frame 박스가 정수 px 라 dp 크기가 소수다(예: kb-tb-dot 5.487×5.5dp). `<img>` 에 소수 `width/height` 를 그대로 주면 Chromium 이 그림 사각형을 기기 px 로 맞춰(스냅) 크기·자리가 최대 1px 바뀐다 — 같은 자리에 찍어 비교하면 shot MAD 가 2.0→10.8(kb-tb-dot)·3.0→8.6(kb-tb-at)·6.2→9.3('2') 로 나빠진다. **정수 width/height(`round(w)`, `round(h)`) + `transform-origin:0 0; transform: translate(소수 left·top) scale(w/W, h/H)`** 로 그리면 위 표의 shot 값이 그대로 나온다. 상자(정수 dp)인 로고·아이콘 SVG 는 상관없다. `WooriArtbox.artBox()` 는 지금 소수 width/height 를 주므로 이 그림들에는 그대로 쓰지 않는다(8절).

## 8. 가정 · 설계값 · 미확정

- **설계값(영상에 없음)**: 탭 전환(자주·내계좌), 증권사 목록, ✕/뒤로로 닫기, ⓧ 지우기, 칩 탭, 7줄 아래 금융회사 — 지어내지 않고 동작만 4절에 적었다. banks.json 의 kftcCode 는 공개 표준 코드(영상에 없음).
- **아이콘 상자**: ‹·✕·카메라·☆·＋·ⓧ·⌄ 의 24/20dp 상자는 잉크 가운데에 맞춘 설계값(json `inkBox` 가 잰 값).
- **선택 알약 높이**: 아래끝이 그림자와 겹쳐 직접 못 잼 → 위끝 + 40dp. 그림자 값(0 1dp 2dp rgba(0,0,0,0.08))은 추정.
- **줄 간격 90.167dp**: 7줄 평균 90.15dp(units.md 90.162). 정수가 아니다 — 타일 높이가 글자 줄 높이(line-height normal)로 정해지는 듯. 높이 82 + 간격 8.167 로 둔다.
- **[확인] 아래 여백 16dp**: 다른 화면 큰 버튼(18dp)과 다름 — 잰 값(1105.43–1187.15px) 그대로.
- **push 곡선**: 허용 없는 맞춤에서 이름 곡선끼리 차이가 작다(3.2). easeOutCubic 322ms 권장, 녹화 비교로 확정(D8).
- **두 번째 push 의 베일**: 첫 push 는 linear 326ms 페이드, 두 번째(금융회사)는 한 프레임에 0.8. 영상 그대로 다르게 둔다.
- **커서 깜빡임**: 13자리 뒤 꺼진 채 952ms — 깜빡임이 멈춘 이유 모름(키보드/IME). 비교는 마스크.
- **칩 로고 한 프레임 옛 그림**: 재현은 선택(2.4).
- **어디로 이체 입력 밑줄 y**: 163.833dp(잰 중심 285.36px). 1/3dp 격자에 딱 맞지 않음(±0.2px 대비 낮은 선).
- **바닥 연락처 줄**: 뷰포트 아래 20dp 에 붙인다고 해석(원 아래끝 780.667). 키보드가 올라오는 화면이 아니라 확인 못 함.
- **스켈레톤 S3b**: 내용으로 바뀌기 한 프레임 전에 스켈레톤 일부가 옅어짐 — 재현 안 해도 됨.
- 영상 안 글자 중 '우리' 칩 하나는 맞춤이 나빠(0.22) 같은 칩 글자 값(15/500)을 따랐다.
- **그림 상자와 소수 크기**: `WooriArtbox.artBox()`(gen 생성)는 소수 width/height 를 준다. 키보드 글자 PNG 9개는 그대로 쓰면 기기 px 스냅으로 일그러진다(6.3) — 정수 크기 + scale 로 그리거나, gen 이 그런 style 을 주도록 고쳐야 한다(도구 주인 결정).

### 9.6 키 눌림

- 숫자 키를 누르면 **키 면 전체가 #808080** (R=G=B=128, 4장 평균) — 글자는 검정 그대로, 상자 그대로(잰 12.2, 818.97, 116.62×84.78 — 눌리지 않은 상자와 같음).

- 기능 키(⌫·이동·.-·,)·빈 키는 영상에서 누르지 않음 → 눌림 색 미상. 설계: 숫자 키와 같은 #808080.

### 9.10 비교 · 마스크 · 가정

- **비교**: 키보드는 앱이 그리므로 `account-keyboard` · `account-typing` · `account-typed` · `account-keyboard-up` 상태에서 **키보드 마스크(0,738,524,542)를 뺐다**(1단계 inventory 는 OS 라 마스크였음 → D5 로 바꿈). 내비 줄(키보드 아이콘)은 기본 마스크로 늘 빠진다. `bank-open`(#2751)은 키보드가 이미 사라진 뒤라 그 마스크도 뺐다.
- 기준 상태들은 키 눌림이 없는 프레임만 쓴다(#2658–#2659, #2698–#2700, #2735–#2738). 눌린 키 상태를 따로 shot 으로 만들지 않았다 — 원본에서 회색인 칸은 실제 숫자라 더미 재생과 다른 칸이다.
- **검증**: 9.1–9.2 의 설계 dp(키 상자·모서리 5dp·색, 글자 빼고)로 키보드 바탕을 그려(10배 슈퍼샘플 → D1 축소) 31장 평균과 비교하면 평균 절대차 **1.14레벨** — 안쪽 0.49, 가장자리 1px 띠 7.6(영상 YUV 4:2:0 색차 번짐; 휘도는 25.5 vs 25.3, 204 vs 207 처럼 맞는다). 스크립트 SP/spec-work/send-a/kb/k17.py.
- **설계값**: 기능 키 눌림 색, ⌫·이동·기호 키 동작(9.9), 숫자 글꼴(Pretendard 근사 — 9.3), 16자리 제한(영상은 13자리까지만 보임).
- **미확정**: 올라옴·내려감 곡선은 VFR 흔들림으로 rms 11.5 / 22px — 녹화 비교로 확정(D8). 내려감 표본은 8장뿐.
- **1단계 기록 고침**: “64.672–64.688 화면 아래 회색(240) 띠”는 회색 띠가 아니라 들어오는 키보드 도구줄(#161518)이다(#2641 64.655 에 이미 1262.5px 까지 올라옴). 키보드 첫 프레임은 64.655.
