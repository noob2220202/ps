## 0. 읽는 법

- **좌표**: `box` = frame px (524x1280, 화면 절대, 상태바 0–45.576 포함). `dp` = 설계 dp, **y 는 앱 뷰포트 기준** (화면 dp − 31.333). 변환은 D1 (가로 `x_dp = 180 + (x_px − 262.02)/1.45803`, 세로 `y_dp = y_px × 0.6875 − 31.333`).
  spec-to-dp 검사 (1부+2부): 설계 dp 1072개, 최대 차이 0.296dp (0.5 넘는 것 없음, dpLoose 없음).
- **(2부 고침) 홈에 가로 치우침은 없다.** 1부는 상자 가운데를 261.52–261.55px 로 재서 "1기기px 왼쪽" 이라 했으나, 1부 측정 함수(rect)가 화소 중심을 정수 좌표로 둔 탓에 가장자리가 가로·세로 모두 **−0.5px** 로 나왔다 (같은 방법으로 상태바/딤 경계를 재면 45.11 — 이론 45.576; 화소 중심 = 정수 + 0.5 로 재면 45.613). 고친 값: 카드 16–344dp (가운데 262.00px = 180.0dp, 글자 가운데와 같음), 공지 카드 위 60dp, 다른 은행 카드 252dp, WON 카드 418.333dp, 흰 카드→파란 띠 562.65dp. 2부가 1부 상자(rect 로 잰 20개)를 +0.5px 옮기고 dp 를 다시 잡았다 (아래 표는 고친 값). 8절.
- **critic (10절)**: 반박 검증에서 머리 52dp · 스켈레톤 카드 264.333dp · 한도제한 칩 20dp · 팝업 흰 띠 756dp · WON 카드 252dp(다른 은행 카드 없을 때) · 마스크 11상태 · AI 반짝이 움직임 · 에셋 6개를 고쳤다.
- **글자**: `woori-textfit` 의 `best` (= 폰 경로로 찾은 크기·굵기·자간 + DSF 16/11 shot 위치). 표의 `left · top` 은 `position:absolute; line-height:1` 의 앱 dp, `translateY(±0.25px)` 는 기준선 행 맞춤. `fit` = design fitError (shot 오차는 json 에 없음 — 0.11–0.34).
  json 의 글자 요소는 `box`/`dp` = line-height:1 줄상자(left · top · advance · font-size), `inkBox` = 잉크, `font.sizePx` = frame px (dp × 16/11), `css` = 그대로 쓰는 CSS.
- **색**: 넓은 면 중앙값 / 글자는 잉크 코어 (tokens.md 1절 방법). 2레벨 안이면 토큰 이름.
- **기준 그림**: `tools/ref/home/<state>.png` = `python3 tools/woori_video.py ref --video vN --i0 '#a' --i1 '#b'` (구간 중앙값). 움직이는 중(CHANGE)인 상태는 가장 대표적인 **한 프레임**을 골랐고, 앱이 같은 위상을 찍도록 `tools/shots.d/home.json` 에 `t` 를 줬다.
- **마스크**(frame px): 캐릭터 대체 그림 `72,236,368,160` (scrollTop s 면 y − s), 홈 위 스피너 `224,546,76,78`, AI 아이콘 `340,60,45,42`(주기 전환이 걸친 구간만), 자동 넘김 중 배너 띠. 기본 마스크(상태바·내비)는 늘 들어간다.

### 2.3 로딩·다시 그리기 상태 (차이만)

## 4. 동작

- **첫 진입** (로그인 뒤): 3.1 단계 → 3.2 공지 줄 정착 → 3.3 팝업 (첫 진입에만) → 3.4 딤 뒤 다른 은행 카드 삽입 → 3.5 오도미터 → "닫기" → 3.6 → 맨 위 정지. 다른 은행 카드는 첫 진입에 팝업 뒤에서 처음 들어온다 (팝업 전 화면에는 없다).
- **팝업**: "닫기" 만 눌렸다(눌림 회색). "오늘은 그만 보기" 동작은 영상에 없음 — 설계: 같은 닫힘 + 오늘 다시 안 띄움. 팝업은 돌아온 홈에서는 뜨지 않는다 (v1 106·v2 0.7 모두 없음).
- **돌아올 때** (거래내역 ‹ 또는 OS 뒤로): 스피너 → 떠날 때 모습(scrollTop·배너 위치·잔액 그대로)을 한 프레임 → 다시 그리기 (3.9 / 3.10). 화면 상태(scrollTop·배너 n)는 세션에 보관.
- **WON 통장 카드 탭** → 3.11 → 거래내역 (`/history?type=all`).
- **AI 아이콘**: 3.8 전역 주기 (누르는 동작은 영상에 없음).
- **스크롤**: 머리·탭바 고정, 내용은 머리 밑으로 들어가며 세로 관성 스크롤 (최대 821dp, 늘어남 없음) + 오버레이 스크롤바 (3.16–3.18).
- **중간 배너**: 자동 넘김 3.0s (3.12), › 탭 (3.13), 손가락 스와이프 (3.14), 10→1 원형. ⏸·‹ 는 영상에서 누르지 않음 — 설계: ⏸ 는 자동 넘김 멈춤/재생 토글(아이콘 ▶ 로), ‹ 는 이전 장 (같은 ease 300ms). 돌아왔을 때 배너 규칙 3.15. 배너 카드 탭(이벤트 페이지)은 영상에 없음.
- **마키**: 늘 흐르고 출렁인다 (3.19–3.20). 카드 탭은 영상에 없음.
- **추천서비스 카드 줄**: 가로 스크롤(둘째 카드가 보임) — 영상에서 넘기지 않음. 공지 줄 탭도 영상에 없음.
- 탭바 다른 탭, 지갑·알림·메뉴, 공지 ✕, 홈계좌설정, 잔액숨김 토글, 다른 은행 계좌 추가, ⋮, 복사, [이체] 는 영상에서 누르지 않았다 (눌림 모양 없음 — 설계 시 tokens.md 눌림 규칙).

## 6. 에셋 요약

`spec/home.assets.json` (43개, 캐릭터 대체 3개) + `frontend/public/woori/home/*`. 이름 = `home.<name>`. 자세한 만든 법·검증·usedIn(상태별 frame 박스)·css 는 json 의 `notes`·`verify`·`usedIn`·`css`.

- **단색(또는 두세 색) 선 아이콘 → SVG** (단위 dp, viewBox = 칸): 모양 변수를 정지 기준 그림에 최소제곱으로 맞춤(frame 화소마다 8x8 표본 덮임 + 코덱 흐림 σ, D1 좌표, 색도 맞춤) → Chromium(DSF 16/11, ?frame=1 셸)에 css 대로 놓고 찍어 `svgFitL1`(휘도 알파 평균 절대차)·relErr·무게중심 차를 기준 그림 2–3장(v1·v2)과 비교. svgFitL1 0.005–0.028, 무게중심 차 ≤0.3px (kebab 0.5–0.9px — 낮은 대비).

## 8. 가정 / 설계값 / 미확정

- **(2부 고침) 1부 상자 −0.5px 오차 — 가로 치우침 없음**: 1부 측정 도우미 `rect`(spec-work/home/scripts/hl.py)는 50% 지점을 `a0 + k + frac` 로 내서 화소 중심을 정수로 본다 → 가장자리가 가로·세로 모두 0.5px 작게 나온다 (units.md 의 calib/mlib.py 는 `+0.5`). 같은 그림에서 +0.5 방식으로 재면 상태바/딤 경계 45.613 (이론 45.576), 내비 경계 1210.108 (이론 1210.182), 카드 가운데 262.00px(180.0dp, 다른 화면과 같음), 공지 카드 위 133.00 (60dp), 다른 은행 카드 412.25 (252dp), 흰 카드→파란 띠 863.97 (562.65dp), 배너 카드 위 1061.7 (698.6dp). 그래서 **"홈 상자만 1기기px 왼쪽" 은 측정 오차**였고 1부 열린 질문(앱 루트 translateX)은 필요 없다. 2부가 rect 로 잰 1부 상자 20개(notice_card, other_card, won_card/container, mode_pill …)를 +0.5px 옮기고 dp 를 1/3dp 로 다시 잡았으며, dp 에서 만든 상자 중 x 가 .667 인 것(카드 15.667, 머리 아이콘 195.667 …)은 +0.333dp 했다 (json `horizontalShift`, 작업 기록 spec-work/home/p2/out/fixlog.json). 1부 글자(textfit)·잉크 상자·탭 아이콘(정수 dp)·이론값 띠(머리·탭바·딤)는 그대로. 1부 글(요약·비고·3절 표)의 px/dp 숫자 몇 개(예: "WON 카드 위끝 앱 251.667dp")는 옛 값이 남아 있다 — 표·json 이 기준.
- **캐릭터 그림**: 방 장면 전체(곰·벌·분홍 캐릭터 + 창문·화분·조명·액자)를 대체 그림으로 본다 (같은 상자 72,236 368x160). 바닥 띠는 바탕(CSS). 대체 그림 디자인은 에셋 단계.
- **탭 '혜택' 아이콘**: 보수적으로 character (대체 + 마스크 454,1132,36,36) — 사용자 확인 필요 (inventory 위험 목록).
- **칩(홈계좌설정·잔액숨김)**: 반투명이라 가장자리 대비가 낮아 위아래 ±1px. 24dp 높이·94dp 폭·α 0.6 은 설계값에 가깝다. 토글 손잡이(12dp, 왼쪽 2dp)는 설계값.
